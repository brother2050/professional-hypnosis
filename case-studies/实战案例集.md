## 案例1：术后急性疼痛管理

**基本信息：**
- 患者：李女士，42岁
- 诊断：子宫肌瘤，行腹腔镜子宫切除术
- 催眠感受性：中等偏高（SHSS:C 8分）

**术前评估：**
- 疼痛恐惧明显（VAS 8/10）
- 焦虑水平高（GAD-7 14分）
- 既往有良好的想象力
- 对催眠持开放态度

**治疗方案：**
- 术前3天：2次催眠准备，教授自我催眠
- 手术当日：术前催眠放松（15分钟）
- 术后：每日1次催眠镇痛（20分钟），配合自我催眠

**催眠干预：**

*术前准备脚本：*
"现在，让我们一起为你的手术做准备...你的身体有强大的愈合能力...手术只是帮助你的身体恢复健康的一个步骤..."

*术后镇痛脚本：*
"现在，你的身体正在开始它的愈合过程...你的内在资源正在帮助你管理任何不适...你可能会注意到一种舒适的感觉开始取代其他感觉..."

**结果：**
- 术后阿片类药物用量减少50%
- 疼痛评分较对照组低2分（NRS）
- 出院时间提前1天
- 3个月随访：无慢性术后疼痛
- 患者满意度：9/10

**关键学习点：**
1. 术前准备对术后效果有重要影响
2. 教授自我催眠增强患者控制感
3. 暗示应与患者的期望和价值观一致
4. 持续的催眠支持促进恢复

## 案例2：慢性腰痛

**基本信息：**
- 患者：王先生，55岁
- 诊断：慢性腰痛（3年）
- 催眠感受性：中等（SHSS:C 6分）

**评估：**
- 疼痛强度：NRS 7/10
- 功能障碍：ODI 45%（中度障碍）
- 伴随：睡眠障碍、轻度抑郁
- 既往治疗：药物、物理治疗，效果有限

**治疗方案：**
- 12周催眠治疗
- 每周1次临床催眠（45分钟）
- 每日自我催眠练习（15分钟）
- 配合物理治疗

**催眠干预重点：**
1. 身体放松与肌肉张力调节
2. 疼痛分离技术
3. 身体意象重建
4. 功能恢复暗示
5. 睡眠改善暗示

**结果：**
- 疼痛强度降低40%（NRS 4/10）
- 功能障碍改善50%（ODI 22%）
- 睡眠质量显著改善
- 抑郁症状减轻
- 6个月随访效果维持

**关键学习点：**
1. 慢性疼痛需要综合性的多模式治疗
2. 催眠可以与其他治疗方法有效整合
3. 自我催眠练习对长期效果至关重要
4. 功能改善与疼痛减轻同样重要

## 案例3：蜘蛛恐惧症

**基本信息：**
- 患者：张女士，28岁
- 主诉：蜘蛛恐惧（从小）
- 催眠感受性：高（SHSS:C 9分）

**评估：**
- 恐惧等级：SUDs 95/100
- 回避行为明显
- 影响日常生活
- 无创伤史

**治疗方案：**
- 6周催眠暴露疗法
- 每周1次治疗（50分钟）
- 每日自我催眠练习

**治疗过程：**

*第1-2周：准备阶段*
- 建立安全地带
- 教授放松和自我催眠
- 建立恐惧等级（10个等级）

*第3-4周：催眠暴露*
- 从最低等级开始（想象"蜘蛛"这个词）
- 逐步递进到看图片
- 在每个等级维持放松状态

*第5-6周：巩固与泛化*
- 暗示在真实情境中的放松
- 规划现实暴露练习
- 建立长期应对策略

**结果：**
- 6周后恐惧等级降至SUDs 20/100
- 能够看蜘蛛图片无明显焦虑
- 3个月后能够接触真实蜘蛛
- 6个月随访效果维持

**关键学习点：**
1. 高感受性个体对催眠暴露反应良好
2. 逐步暴露配合催眠放松效果显著
3. 安全地带的建立对治疗至关重要
4. 现实暴露是巩固效果的关键

## 案例6：广泛性焦虑障碍（GAD）

**基本信息：**
- 患者：林女士，38岁，公司高管
- 诊断：广泛性焦虑障碍（GAD）
- 催眠感受性：中等（SHSS:C 7分）
- 病程：3年

**评估：**
- GAD-7：18分（重度焦虑）
- PHQ-9：12分（中度抑郁）
- PSQI：14分（睡眠障碍）
- 疼痛：头痛VAS 6/10
- 功能：工作能力下降，人际关系紧张

**治疗方案：**
- 12周催眠认知行为治疗（CBH）
- 每周1次临床催眠（50分钟）
- 每日自我催眠练习（15分钟）
- 配合认知行为技术

**治疗内容：**

**第1-3周：建立与稳定**
- 全面评估和个案概念化
- 安全地带建立
- 基础放松和自我催眠训练
- 心理教育

**第4-6周：技能培养**
- 认知重构催眠
- 情绪调节暗示
- 注意力训练暗示
- 身体放松深化

**第7-9周：深度处理**
- 焦虑根源探索
- 核心信念重构
- 情绪释放处理
- 自信建立暗示

**第10-12周：整合与维持**
- 未来导向暗示
- 复发预防策略
- 长期自我管理计划
- 随访计划制定

**结果：**
- 12周后：
  - GAD-7：6分（轻度焦虑，降低67%）
  - PHQ-9：5分（无抑郁，降低58%）
  - PSQI：7分（睡眠改善，降低50%）
  - 头痛：VAS 2/10（降低67%）
  - 工作能力恢复
  - 人际关系改善
- 6个月随访：效果维持
- 1年随访：持续改善
- 患者满意度：10/10

**关键学习点：**
1. GAD需要综合性的催眠认知行为治疗
2. 自我催眠练习对长期效果至关重要
3. 认知重构催眠可以有效改变焦虑思维模式
4. 安全地带建立是治疗的基础

- 评估方案优劣
