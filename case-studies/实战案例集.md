## 案例1：术后急性疼痛管理

**适用场景关键词**：围手术期疼痛｜术前准备｜阿片减量｜自我催眠

**基本信息：**
- 患者：李女士，42岁
- 诊断：子宫肌瘤，行腹腔镜子宫切除术
- 催眠感受性：中等偏高（SHSS:C 8分）

**术前评估：**
- 疼痛恐惧明显（VAS 8/10）
- 焦虑水平高（GAD-7 14分）
- 既往有良好的想象力
- 对催眠持开放态度

**治疗方案：**
- 术前3天：2次催眠准备，教授自我催眠
- 手术当日：术前催眠放松（15分钟）
- 术后：每日1次催眠镇痛（20分钟），配合自我催眠

**催眠干预：**

*术前准备脚本：*
“现在，让我们一起为你的手术做准备...你的身体有强大的愈合能力...手术只是帮助你的身体恢复健康的一个步骤...”

*术后镇痛脚本：*
"现在，你的身体正在开始它的愈合过程...你的内在资源正在帮助你管理任何不适...你可能会注意到一种舒适的感觉开始取代其他感觉..."

**结果：**
- 术后阿片类药物用量减少50%
- 疼痛评分较对照组低2分（NRS）
- 出院时间提前1天
- 3个月随访：无慢性术后疼痛
- 患者满意度：9/10

**关键学习点：**
1. 术前准备对术后效果有重要影响
2. 教授自我催眠增强患者控制感
3. 暗示应与患者的期望和价值观一致
4. 持续的催眠支持促进恢复

**决策点复盘**：①选「术前准备＋术后镇痛」而非术后单次——手术可预期，提前建资源才覆盖全围术期；判据：手术日已定、对催眠开放。②先镇恐惧（VAS 8/10）再镇痛，跳过则一疼就破功。③另一条路：纯药物省事但阿片用量高。配套：脚本16、练习3.1。

## 案例2：慢性腰痛

**适用场景关键词**：慢性疼痛｜腰痛｜多模式治疗｜功能恢复

**基本信息：**
- 患者：王先生，55岁
- 诊断：慢性腰痛（3年）
- 催眠感受性：中等（SHSS:C 6分）

**评估：**
- 疼痛强度：NRS 7/10
- 功能障碍：ODI 45%（中度障碍）
- 伴随：睡眠障碍、轻度抑郁
- 既往治疗：药物、物理治疗，效果有限

**治疗方案：**
- 12周催眠治疗
- 每周1次临床催眠（45分钟）
- 每日自我催眠练习（15分钟）
- 配合物理治疗

**催眠干预重点：**
1. 身体放松与肌肉张力调节
2. 疼痛分离技术
3. 身体意象重建
4. 功能恢复暗示
5. 睡眠改善暗示

**结果：**
- 疼痛强度降低40%（NRS 4/10）
- 功能障碍改善50%（ODI 22%）
- 睡眠质量显著改善
- 抑郁症状减轻
- 6个月随访效果维持

**关键学习点：**
1. 慢性疼痛需要综合性的多模式治疗
2. 催眠可以与其他治疗方法有效整合
3. 自我催眠练习对长期效果至关重要
4. 功能改善与疼痛减轻同样重要

**决策点复盘**：①12 周长程＋每日自我催眠而非单次——病程 3 年伴失眠抑郁，短期暗示压不住；判据：ODI 45%、药物与理疗效果有限。②「功能改善」与「疼痛减轻」并列目标，只盯分数易脱落。③另一条路：纯镇痛暗示快但易反复；与物理治疗并行先分工。配套：脚本3＋7、练习3.2。

## 案例3：蜘蛛恐惧症

**适用场景关键词**：特定恐惧｜恐惧等级｜系统脱敏｜安全地带

**基本信息：**
- 患者：张女士，28岁
- 主诉：蜘蛛恐惧（从小）
- 催眠感受性：高（SHSS:C 9分）

**评估：**
- 恐惧等级：SUDs 95/100
- 回避行为明显
- 影响日常生活
- 无创伤史

**治疗方案：**
- 6周催眠暴露疗法
- 每周1次治疗（50分钟）
- 每日自我催眠练习

**治疗过程：**

*第1-2周：准备阶段*
- 建立安全地带
- 教授放松和自我催眠
- 建立恐惧等级（10个等级）

*第3-4周：催眠暴露*
- 从最低等级开始（想象“蜘蛛”这个词）
- 逐步递进到看图片
- 在每个等级维持放松状态

*第5-6周：巩固与泛化*
- 暗示在真实情境中的放松
- 规划现实暴露练习
- 建立长期应对策略

**结果：**
- 6周后恐惧等级降至SUDs 20/100
- 能够看蜘蛛图片无明显焦虑
- 3个月后能够接触真实蜘蛛
- 6个月随访效果维持

**关键学习点：**
1. 高感受性个体对催眠暴露反应良好
2. 逐步暴露配合催眠放松效果显著
3. 安全地带的建立对治疗至关重要
4. 现实暴露是巩固效果的关键

**决策点复盘**：①先建安全地带（第 1-2 周）再暴露——判据：能说出安全地点并报告放松；跳过易二次创伤。②从最低级（想象「蜘蛛」一词）逐级到图片——判据：每级 SUDs 降到 3 以下再升级。③另一条路：直接现实暴露快但脱落率高。配套：脚本2→14、练习2.3。

## 案例4：考试焦虑

**适用场景关键词**：考试焦虑｜灾难化思维｜成功想象｜学生

**基本信息：**
- 患者：刘同学，20岁，大学生
- 主诉：考试焦虑（2年）
- 催眠感受性：中等（SHSS:C 7分）

**评估：**
- 考试焦虑量表：高分
- 伴随：失眠、注意力困难
- 影响：成绩下降、自信降低
- 目标：改善考试表现

**治疗方案：**
- 8周催眠治疗
- 每周1次治疗（40分钟）
- 每日自我催眠练习

**催眠干预重点：**
1. 放松训练
2. 认知重构（改变对考试的灾难化思维）
3. 自信心建立
4. 考试场景想象（成功想象）
5. 注意力集中暗示

**结果：**
- 考试焦虑显著降低
- 考试成绩改善
- 自信心增强
- 睡眠改善

**决策点复盘**：①放松＋认知重构＋成功想象三件套——判据：焦虑以灾难化思维为主，只做放松，进考场念头一转就崩。②每日自我催眠巩固；做不到改考前 2 周集中做。③另一条路：考场脱敏＋应急方案（案例18），适合只剩 5 周。配套：脚本15、练习2.1。

## 案例5：戒烟

**适用场景关键词**：戒烟｜单次强化｜动机评估｜复发预防

**基本信息：**
- 患者：赵先生，45岁
- 主诉：戒烟（吸烟25年）
- 催眠感受性：中等偏高（SHSS:C 8分）

**评估：**
- 每日吸烟量：20支
- 既往戒烟尝试：3次（均失败）
- 动机：健康考虑、家庭期望
- 依赖程度：高（Fagerström 8分）

**治疗方案：**
- 单次强化催眠戒烟（90分钟）
- 后续2次跟进治疗
- 自我催眠练习

**催眠干预重点：**
1. 增强戒烟动机
2. 改变对吸烟的联想
3. 建立厌恶暗示
4. 增强自我控制感
5. 复发预防暗示

**结果：**
- 治疗后立即停止吸烟
- 1个月随访：完全戒断
- 3个月随访：偶有渴望但能应对
- 6个月随访：完全戒断
- 1年随访：保持戒断

**关键学习点：**
1. 高感受性个体戒烟成功率更高
2. 单次强化催眠可能有效
3. 后续跟进对维持效果重要
4. 自我催眠练习增强长期效果

**决策点复盘**：①单次强化 90 分钟＋2 次跟进——判据：动机强、感受性中高；动机弱先做动机访谈。②厌恶暗示必须配替代行为，否则复吸率高。③另一条路：渐进减量 4-6 周。与案例11 对照：依赖越重，跟进越密。配套：脚本13、练习3.3。

## 案例6：广泛性焦虑障碍（GAD）

**适用场景关键词**：广泛性焦虑｜CBH｜稳定化｜共病抑郁失眠

**基本信息：**
- 患者：林女士，38岁，公司高管
- 诊断：广泛性焦虑障碍（GAD）
- 催眠感受性：中等（SHSS:C 7分）
- 病程：3年

**评估：**
- GAD-7：18分（重度焦虑）
- PHQ-9：12分（中度抑郁）
- PSQI：14分（睡眠障碍）
- 疼痛：头痛VAS 6/10
- 功能：工作能力下降，人际关系紧张

**治疗方案：**
- 12周催眠认知行为治疗（CBH）
- 每周1次临床催眠（50分钟）
- 每日自我催眠练习（15分钟）
- 配合认知行为技术

**治疗内容：**

**第1-3周：建立与稳定**
- 全面评估和个案概念化
- 安全地带建立
- 基础放松和自我催眠训练
- 心理教育

**第4-6周：技能培养**
- 认知重构催眠
- 情绪调节暗示
- 注意力训练暗示
- 身体放松深化

**第7-9周：深度处理**
- 焦虑根源探索
- 核心信念重构
- 情绪释放处理
- 自信建立暗示

**第10-12周：整合与维持**
- 未来导向暗示
- 复发预防策略
- 长期自我管理计划
- 随访计划制定

**结果：**
- 12周后：
  - GAD-7：6分（轻度焦虑，降低67%）
  - PHQ-9：5分（无抑郁，降低58%）
  - PSQI：7分（睡眠改善，降低50%）
  - 头痛：VAS 2/10（降低67%）
  - 工作能力恢复
  - 人际关系改善
- 6个月随访：效果维持
- 1年随访：持续改善
- 患者满意度：10/10

**关键学习点：**
1. GAD需要综合性的催眠认知行为治疗
2. 自我催眠练习对长期效果至关重要
3. 认知重构催眠可以有效改变焦虑思维模式
4. 安全地带建立是治疗的基础

**决策点复盘**：①四阶段（稳定→技能→深度→整合），前 3 周只做稳定——判据：GAD-7 18 分伴抑郁失眠，直接挖根源会加重失眠。②认知重构催眠为主轴（灾难化思维明显）。③另一条路：药物或纯 CBT；整合方案要写清分工。配套：脚本2＋8、练习3.1。

## 案例7：社交焦虑障碍（SAD）

**适用场景关键词**：社交焦虑｜想象暴露｜现实暴露｜自我效能

**基本信息：**
- 患者：赵先生，25岁，研究生
- 诊断：社交焦虑障碍
- 催眠感受性：高（SHSS:C 9分）
- 病程：5年

**评估：**
- LSAS：90分（重度社交焦虑）
- 自我效能感：低
- 回避行为：明显
- 功能：学业和社交受限

**治疗方案：**
- 10周催眠暴露治疗
- 每周1次临床催眠（50分钟）
- 每日自我催眠练习（20分钟）
- 配合现实暴露练习

林女士，38岁，企业中层管理者。主诉入睡困难伴日间焦虑1年余。近一年因部门重组、考核压力增大，逐渐出现入睡潜伏期超过1小时，夜间频繁觉醒，晨起不解乏。日间表现为心慌、肩颈紧张、反复担忧工作出错。匹兹堡睡眠质量指数（PSQI）14分，广泛性焦虑量表（GAD-7）16分（中重度）。已在三甲医院排除甲状腺功能亢进等器质性问题，短期服用唑吡坦后担心依赖而主动寻求非药物干预。

3. **第3次·刺激控制与意象脱敏**：重建“床=睡眠”联结（20分钟未入睡即离床），对“想到明天汇报”的侵入性担忧做意象预演：想象把担忧写在纸上放进抽屉，明早9点再打开。
4. **第4次·认知重构**：用后催眠暗示松动“睡不着就完了”的灾难化信念，植入“身体会自动休息，睡眠会自然来”的新叙事；加入艾瑞克森式隐喻（“守夜人的故事”）。
5. **第5次·日间焦虑管理**：教“担忧时间”技术（每天固定15分钟处理担忧），肩颈紧张处做“温热手套”意象自我暗示，训练快速放松锚（拇指—食指捏合）。

**结果**
5次结束时10指中8指指甲明显生长，仅右手食指偶有咬痕（对应旧甲沟炎习惯点），代币系统执行良好，被同学取笑事件未再困扰。3个月随访：指甲全部恢复正常长度，咬指甲行为基本消失（母亲记录每周≤2次轻咬），“魔法手套”用于考前紧张时自我安抚。

**决策点复盘**：①游戏化隐喻＋代币系统，行为框架不省——判据：感觉调节型习惯，纯暗示压不住动作链。②父母指导先行（停批评、停涂苦药水），撤除负性关注常立竿见影。③替代行为配触发情境（写作业转笔帽、看电视捏球），笼统的「别咬了」无效。④允许复发叙事（「黑雾怪会回来」）降羞耻，反而提升长期维持。配套：练习册模块C2、脚本15 的触发锚思路。
