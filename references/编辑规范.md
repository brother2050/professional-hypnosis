# 编辑规范（全书质量守则）

> **用途**：本文件固化本书 1.2.x 系列审校确立的写作与编辑规范，供后续修订者遵循，避免质量回退。
> **原则**：真实优先、读者优先、一致优先。

---

## 1. 证据与真实性（最高优先级）

1. **禁止编造**：不得出现虚构的研究、作者、期刊、卷期页、数据表、统计数字（效应量/样本量/p 值/百分比）、判例、事件。
2. **引文规则**：只保留能出示核实来源（PubMed/DOI/期刊官网）的引文；精确卷期页只有与核实结果完全一致才保留，否则降级为（作者，年份）。
3. **统计数字**：只在有可核实来源时出现；无来源时写定性表述（"效应量中等""证据有限，结论尚不一致"）。
4. **教学案例**：一律标注"教学性改编示例，人物、数字为示意，非真实患者记录"；判例与事件改为情景时标注"教学情景示例，非真实判例/事件"。
5. **文献清单**：新引文须同步登记到 `references/verification-status.md`；拿不准 → 删除或定性化，不保留"看起来很权威"的精确值。

## 2. 术语与表述

1. **规范术语**：催眠感受性（不用"催眠易感性/可催眠性"）、后催眠暗示（不用"催眠后暗示"）、暗示感受性（suggestibility，与催眠感受性区分）。
2. **术语入表**：新增术语同步补入附录 B（纯释义，不带研究结论）。
3. **禁止 AI 腔套话**："值得注意的是""总而言之""不难发现"等引导语不使用；用具体判断句替代。
4. **主次分层**：学习类内容用 ⭐必须掌握 / ◐理解 / ○了解 三级标注；了解级内容不得混入重点。

## 3. 排版与标点

1. **中文语境用全角**：逗号、句号、冒号、问号、分号、叹号、括号、引号（""）。省略号"…"在催眠台词中作停顿标记可用三个句点。
2. **参考文献条目**用半角学术格式（Author, A. (2000). *Title*. Publisher.）。
3. **引文格式**：中文作者用"王明辉等，2024"或"（王明辉等，2024）"；拉丁作者用"（Author et al., 2020）"。
4. **标题**：章节标题格式 `## X.Y 标题`（数字后空格）；附录标题 `# 附录X：标题`；文件名与内部编号必须一致。

## 4. 结构与导航

1. **章节四件套**：📋 核心内容摘要 → 正文 → 延伸阅读（或参考文献）→ 实践思考题 → 关键术语中英对照 → 章尾 `[← 返回目录](../README.md)`。
2. **节号连续**：删除小节后必须顺位重编号；全书交叉引用（"X.Y 节"）必须随重编号同步校验。
3. **重复内容**：实质内容只在一处完整展开，其他位置用摘要+指路（"详见第N章/附录X"）；标准安全声明、表单模板、速用手册收录的脚本允许有意重复。
4. **README 同步**：新增/删除文件、统计变化、重大修订须更新 README（目录、统计、更新日志、版本号与日期）。

## 5. 安全与伦理内容

1. 安全红线（不恢复记忆/不替代医疗/无知情同意不动手）在涉及实践的文档中不得弱化。
2. 涉及儿童、创伤、司法、AI 工具的内容必须保留风险提示与边界说明。
3. 疗效表述不承诺结果（"只承诺过程"）；示例数字必须带"示意"标注。

## 6. 修订流程

1. 改动前先看本文件与 `references/verification-status.md`。
2. 批量修改后跑四项检查：坏链、锚点、代码围栏平衡、中文语境半角标点。
3. 提交信息写明做了什么；更新日志记入 README；版本号递增（v1.2.x 维护系列）。
4. 不确定的改动 → 保留原文并标注疑问，不擅自"编一个合理的"。
