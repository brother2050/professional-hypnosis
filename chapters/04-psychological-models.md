# 第4章 催眠心理学理论模型

## 4.1 分离理论（Dissociation Theory）

### 4.1.1 希尔加德的新分离理论

**核心主张（Hilgard, 1977, 1991）：**

催眠状态涉及意识系统的功能性分裂（functional division），意识中存在多个独立运作的子系统。在催眠状态下，某些意识子系统可以独立于主体意识进行加工。

**"隐藏观察者"实验：**

希尔加德的经典实验设计：
1. 对高感受性被试进行催眠镇痛暗示
2. 被试报告不感到疼痛
3. 同时要求被试用非优势手在写字板上写下真实感受
4. 结果：被试的口头报告是"无痛"，但非优势手写出"很痛，但被忽略了"

**解释：** 这表明意识中存在一个"隐藏的观察者"——一个持续监测和记录真实体验的意识子系统，即使在催眠健忘状态下仍然活跃。

**理论模型图示：**

```
        ┌─────────────────────────────┐
        │       总体意识系统          │
        │  ┌─────────┐  ┌─────────┐  │
        │  │ 子系统A │  │ 子系统B │  │
        │  │ (口头   │  │ (书写   │  │
        │  │  报告)  │  │  通道)  │  │
        │  └────┬────┘  └────┬────┘  │
        │       │            │       │
        │  ┌────┴────┐  ┌────┴────┐  │
        │  │催眠暗示 │  │隐藏    │  │
        │  │覆盖通道 │  │观察者  │  │
        │  └─────────┘  └─────────┘  │
        └─────────────────────────────┘
```

### 4.1.2 分离理论的现代发展

**Woody & Sadler (2005) 的整合分离模型：**

将分离理论与认知控制理论整合，提出：
- 催眠涉及执行控制功能的分离
- 某些执行控制功能被"委托"给催眠暗示
- 这种分离是可控的、可逆的

**分离理论的证据：**
- 催眠健忘时隐性记忆仍然存在
- 催眠镇痛时生理反应仍然可检测到
- "隐藏观察者"现象在多个实验室被复制

**分离理论的局限：**
- 隐藏观察者的本质仍有争议（可能是策略性报告）
- 难以区分"真正的分离"和"报告偏差"
- 对催眠暗示的具体机制解释不够

## 4.2 社会认知理论（Social Cognitive Theory）

### 4.2.1 角色扮演理论

**萨尔帕斯的理论（Spanos, 1986, 1991）：**

催眠不是特殊意识状态，而是：
1. 一种社会角色的扮演
2. 催眠被试按照社会期望行事
3. 催眠行为是策略性信息加工的结果
4. 催眠体验是被试对自己行为的归因

**关键概念：**

- **情境定义（Situation Definition）**：被试对催眠情境的理解影响其行为
- **目标导向策略（Goal-Directed Strategies）**：被试使用各种策略来产生催眠反应
- **体验归因（Experiential Attribution）**：被试将自己的行为归因为催眠状态

### 4.2.2 期望-响应理论

**基尔希的理论（Kirsch, 1985, 2011）：**

催眠反应的核心机制是响应期望（Response Expectancy）：
1. 被试对催眠暗示的响应产生预期
2. 这种预期本身直接产生相应的体验
3. 期望效应不需要意识努力
4. 催眠感受性反映的是对暗示的期望强度

**支持证据：**
- 期望操纵可以显著影响催眠反应
- 催眠诱导前的期望可以预测催眠反应
- 安慰剂效应与催眠效应有共同机制

### 4.2.3 体验性理论

**巴伯的理论（Barber, 1969）：**

催眠反应的关键不是"催眠状态"，而是：
1. 对催眠情境的积极态度
2. 想象参与（imaginative involvement）
3. 动机（motivation）
4. 对任务的理解（task-appropriate attitudes）

**巴伯的"任务动机"范式：**
- 不使用正式催眠诱导
- 仅通过指导语和动机操纵
- 可以产生与催眠相似的暗示响应

## 4.3 认知理论

### 4.3.1 管理控制系统理论

**Woody & Bowers (1994) 的理论：**

借鉴认知心理学的管理控制系统（Supervisory Control System）模型：
- 正常行为由自动化的前馈控制系统管理
- 管理控制系统负责对自动化行为进行监控和修正
- 催眠暗示通过抑制管理控制系统，使前馈控制系统直接运行
- 这解释了催眠行为的自动性和非自主感

### 4.3.2 认知解离理论

**Dienes & Perner (2007) 的理论：**

催眠涉及对高阶思维的抑制：
1. 正常情况下，我们对信念进行二阶表征（"我相信P"）
2. 催眠暗示抑制了这种二阶表征
3. 导致一阶信念直接驱动体验（直接"知道"P）
4. 这种高阶思维的缺失使暗示能够直接影响体验

### 4.3.3 执行功能理论

**Egner & Raz (2007) 的理论：**

将催眠与执行功能研究整合：
- 催眠暗示影响注意控制、工作记忆和冲突监测
- 不同的催眠暗示影响不同的执行功能成分
- 催眠感受性与执行功能的个体差异相关

## 4.4 神经生物学理论

### 4.4.1 前额叶功能理论

**Gruzelier (2000, 2006) 的理论：**

将催眠与前额叶不对称性和功能联系：
- 催眠诱导涉及从左前额叶（分析性、自我参照）到右前额叶（整体性、直觉性）的转换
- 高感受性个体的额叶功能具有特定的不对称性模式
- 不同类型的催眠暗示影响不同的额叶区域

### 4.4.2 预测编码理论

**应用预测编码框架解释催眠（Lush et al., 2020; Terhune et al., 2017）：**

- 大脑不断生成对感觉输入的预测
- 催眠暗示修改了高层级的预测
- 催眠态下，预测对感觉证据的影响力增强
- 这解释了催眠感觉改变的机制

**具体应用：**
- 催眠镇痛：暗示改变痛觉预测，使痛觉信号被解释为无害
- 催眠幻觉：暗示产生的预测足够强，取代实际感觉输入
- 催眠健忘：暗示阻断了记忆提取的预测通路

## 4.5 整合模型

### 4.5.1 生物-心理-社会整合模型

**当代共识性理解（Lynn et al., 2020）：**

催眠不能被单一理论完全解释，需要整合多个层面的因素：

**生物层面：**
- 神经网络活动模式的改变
- 基因和神经递质的个体差异
- 神经可塑性的参与

**心理层面：**
- 注意力调节机制
- 期望和信念效应
- 想象和表象加工
- 认知控制的改变

**社会层面：**
- 催眠情境的社会定义
- 催眠师-来访者关系
- 文化背景的影响
- 社会期望效应

### 4.5.2 多阶段整合模型

```
    ┌──────────────────────────────────────┐
    │         个体差异因素                  │
    │  (感受性、期望、动机、人格)           │
    └───────────────┬──────────────────────┘
                    │
                    ▼
    ┌──────────────────────────────────────┐
    │         催眠诱导过程                  │
    │  (注意力聚焦、想象引导、暗示)         │
    └───────────────┬──────────────────────┘
                    │
                    ▼
    ┌──────────────────────────────────────┐
    │         意识状态改变                  │
    │  (脑网络重组、前额叶功能变化)         │
    └───────────────┬──────────────────────┘
                    │
                    ▼
    ┌──────────────────────────────────────┐
    │         暗示响应机制                  │
    │  (预测修改、认知控制改变、分离)       │
    └───────────────┬──────────────────────┘
                    │
                    ▼
    ┌──────────────────────────────────────┐
    │         行为/体验/生理改变            │
    │  (感觉改变、记忆改变、行为改变)       │
    └──────────────────────────────────────┘
```

## 4.6 理论评价与未来方向

### 4.6.1 各理论的优缺点比较

| 理论 | 优势 | 局限 |
|------|------|------|
| 分离理论 | 解释隐藏观察者、催眠健忘 | 分离的定义模糊 |
| 社会认知理论 | 强调社会因素、可检验 | 忽略神经机制 |
| 认知理论 | 整合认知科学框架 | 实证支持有限 |
| 神经生物学理论 | 有神经影像证据支持 | 模型过于简化 |
| 预测编码理论 | 整合性强、解释范围广 | 仍在发展中 |

### 4.6.2 未来研究方向

1. **多层面整合**：发展涵盖神经、认知、社会的整合理论
2. **个体化理论**：解释为什么不同个体对催眠的反应不同
3. **现象学与机制的桥梁**：连接催眠的主观体验与神经机制
4. **跨学科对话**：促进神经科学、认知科学和社会心理学的交流
