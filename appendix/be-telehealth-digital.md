# 附录 BE 催眠与远程医疗 / 数字疗法

> **定位**：本附录面向临床催眠师、数字健康产品设计者、医疗信息化管理者及政策制定者，系统阐述催眠在远程医疗（Telehealth）与数字疗法（Digital Therapeutics, DTx）语境下的技术规范、产品设计、循证基础与伦理治理。可作为远程催眠服务建设、催眠类数字产品开发与审评的参考手册。

## BE.1 远程医疗的发展与催眠的数字化转型

### BE.1.1 远程医疗的演进脉络

远程医疗经历了四个阶段：

1. **第一代（1960s–1990s）**：以电话、传真和点对点视频会诊为主，服务于偏远地区的专科可及性问题。
2. **第二代（2000s）**：宽带网络与医疗信息系统（HIS/PACS）普及，远程影像、远程心电等"数据驱动"专科兴起。
3. **第三代（2010s）**：移动医疗（mHealth）与可穿戴设备出现，监测数据实时回传，慢病管理走向家庭。
4. **第四代（2020s–）**：AI 辅助决策、VR/AR 沉浸式干预、数字疗法处方化，远程医疗从"替代线下"转向"原生数字化干预"。

新冠疫情（2020–2023）是远程医疗的分水岭：多国监管机构临时放开远程诊疗限制，精神卫生与行为干预成为远程渗透率最高的科室之一。催眠作为一种高度依赖语言引导、暗示与想象的干预方式，天然适合"屏幕内的咨询室"——这为催眠的数字化转型提供了历史性窗口。

### BE.1.2 催眠为何适合远程化

催眠干预的核心要素可以被完整地编码、传输与复现：

| 干预要素 | 线下形态 | 远程/数字化形态 |
|---|---|---|
| 诱导语言（语调、节奏、停顿） | 治疗师现场发声 | 高保真音频流、预录脚本、TTS 合成 |
| 暗示内容 | 口头暗示 | 个性化脚本模板 + AI 生成 |
| 想象场景 | 治疗师口头描绘 | VR/AR 沉浸场景、360° 音视频 |
| 生理反馈（放松指标） | 治疗师观察 | 可穿戴设备（HRV、EDA、EEG） |
| 治疗关系 | 面对面 | 视频在场（therapeutic presence） |
| 家庭作业 | 嘱咐练习 | App 推送、数字日记、依从性追踪 |

同时，催眠具有**可自我施用（self-hypnosis）**的悠久传统，这与数字疗法强调的"患者自主、持续干预"理念高度契合。

### BE.1.3 数字化转型的三层架构

1. **服务层（Tele-hypnosis）**：通过视频会议系统提供实时远程催眠治疗，保留治疗师主导。
2. **产品层（Hypnosis Apps / DTx）**：结构化催眠程序被封装为软件，患者按方案自主使用。
3. **平台层（AI + 数据）**：以数据闭环驱动个性化推荐、疗效预测与风险监控，形成"数字催眠生态系统"。

三层并非替代关系，而是**阶梯式照护（stepped care）**：低风险人群使用自助型产品，中高风险人群在产品基础上叠加远程治疗师督导，高风险/难治性个案回归线下或混合（blended）模式。

## BE.2 远程催眠的实施规范

### BE.2.1 技术要求

**硬件与环境**
- 治疗端：≥1080p 摄像头、全频带麦克风（建议外接心形指向麦克风以减少环境噪声）、双屏（一屏观察来访者，一屏查看脚本与记录）。
- 来访者端：稳定的网络（上行 ≥5 Mbps）、耳机（**强烈推荐封闭式耳机或入耳式耳机**，以保证诱导语音的私密性与沉浸感）、安静不被打扰的独立空间、可后仰的座椅或沙发（避免躺卧入睡）。
- 兜底方案：必须约定网络中断时的**备用通道**（如电话拨入），并在会谈开始前测试。

**平台与合规**
- 采用端到端加密（E2EE）的合规视频平台（符合 HIPAA / GDPR / 中国《个人信息保护法》及《互联网诊疗管理办法》相应要求），禁用会话云录制除非获得单独书面同意。
- 会话日志、知情同意书、评估量表应进入加密的电子病历系统（EMR），保留完整的审计追踪。
- 时间同步与会话时长记录自动化，用于疗效剂量分析。

**催眠特异性技术检查**
- 音频延迟测试：**单向延迟 >300 ms** 会显著破坏诱导节奏，需提前检测并优化路由。
- 音量一致性：避免自动增益控制（AGC）忽大忽小，建议关闭系统级音频增强。
- 灯光与画面：治疗师面部清晰可见、无逆光；来访者画面应覆盖上半身，便于观察呼吸与肌张力变化。
- 来访者姿态安全：确认其不在驾驶、操作机械、泡澡或独自照护婴幼儿的状态下接受催眠。

### BE.2.2 安全协议

1. **身份与状态确认**：每次会话开始确认来访者身份、所在地点（以便紧急情况下联络当地急救）、当前生理与情绪状态（0–10 主观困扰评分）。
2. **禁忌与筛查**：精神病性障碍急性期、急性自杀/自伤风险、解离性障碍未稳定、严重心血管疾病（针对强烈情绪唤起类暗示）、癫痫光敏性（针对 VR 闪烁场景）须转介或在精神科协同下进行。
3. **催眠中风险处置**：
   - 出现过度换气、惊恐、侵入性创伤画面 → 立即中止深化，转入**定向（orienting）与稳定化**技术（"现在睁开眼睛，看看房间里的三样东西……"）。
   - 出现异常意识状态或疑似解离 → 记录现象、恢复普通对话、评估是否需要线下精神科会诊。
   - 来访者意外入睡 → 唤醒程序：倒数 5-4-3-2-1 + 明确唤醒暗示 + 5 分钟定向谈话后方可结束会谈。
4. **会谈后确认**：来访者完全清醒、定向力完整、无明显头晕/情绪残留，方可结束视频连接；必要时安排 24 小时内随访消息。
5. **紧急预案**：保存来访者所在地紧急联系人、最近医疗机构、心理危机热线（如北京心理危机研究与干预中心 010-82951332、全国 24 小时心理援助热线 12356）；协议中明确"何种情况下启动危机响应"。

### BE.2.3 知情同意

远程催眠的知情同意书应至少包含：

1. **干预性质**：催眠的状态模型与社会认知模型说明、预期疗效与常见不适（短暂头晕、情绪波动、记忆重构性不适）。
2. **远程模式的特殊性与局限**：网络中断风险、无法进行躯体急救、居家环境不可控因素、录音录像可能性。
3. **数据处理**：采集哪些数据（会话元数据、量表、可穿戴生理数据、App 使用日志）、存储期限、跨境传输、二次科研使用的单独授权选项。
4. **自主权**：来访者**随时可自行退出催眠状态**的告知（"催眠不是被控制，您可以随时拒绝任何暗示"）、拒绝某条暗示的权利。
5. **替代方案**：线下治疗、其他心理治疗或药物治疗的选择权。
6. **未成年与特殊人群**：监护人同意 + 未成年人适龄同意（assent）。
7. **危机与免责条款**：远程服务不替代紧急医疗救助。

建议采用**分层式同意（tiered consent）**：基础治疗同意、录制同意、数据用于研究同意、AI 辅助决策同意分别独立勾选，避免"一揽子"授权。

## BE.3 催眠 App 的设计原则与评估标准

### BE.3.1 设计原则

**P1 临床结构化优先**：App 的每一分钟内容都应映射到明确的临床阶段——准备/心理教育 → 诱导 → 深化 → 治疗性暗示/意象 → 唤醒 → 整合。禁止"只有放松音乐"冒充催眠干预。

**P2 个体化而非千人一面**：至少支持以下维度的可配置性——
- 诱导风格偏好（直接式/授权式/意象式/困惑式）
- 感官通道偏好（视觉型/听觉型/动觉型，可通过 VAK 问卷或使用行为推断）
- 时长（5 分钟微干预至 45 分钟完整会话）
- 文化适配（意象的本地化：海、山、庭院等场景的文化接受度）
- 语言与语音（音色、语速、口音、性别偏好）

**P3 意象而非抽象说教**：催眠的核心是生成性意象。设计上应以**引导式想象场景库**为核心资产，配合可选的 360° 环境音/自然声景。

**P4 可测量的依从性**：埋点记录开始率、完成率、中途退出时间点、重复使用率；以"完成核心剂量"（如 4 周内 ≥12 次会话）作为临床有效性的前置指标。

**P5 安全护栏**：
- 唤醒段不可跳过（禁用"跳到最后"或倒计时可被中止）；
- 每次会话前后状态检查（简短 PHQ-2/GAD-2 或 SUD 评分）；
- 内置风险升级路径：高危问卷得分触发"请立即联系真人支持"的弹窗与一键拨打；
- 驾驶/操作机械场景的强警告。

**P6 不制造依赖**：设计退出路径——症状缓解后引导至自主自我催眠、降低使用频次、明确"工具而非拐杖"的产品哲学。

**P7 无障碍设计**：视障用户的完整音频替代、听障用户的字幕 + 震动节律引导、老年用户的大字号与简化导航。

### BE.3.2 评估标准（六维评分）

| 维度 | 关键指标 | 及格线建议 |
|---|---|---|
| **临床有效性** | RCT 效应量（Hedges' g）、症状量表改善率 | g ≥ 0.4 且优于主动对照 |
| **安全性** | 不良事件率、风险升级流程可用性 | 严重不良事件 0；流程演练通过 |
| **可用性** | SUS 量表、任务完成率 | SUS ≥ 68 |
| **依从性** | 4 周留存、单次完成率 | 完成率 ≥ 60% |
| **隐私合规** | 数据最小化、加密、第三方 SDK 审计 | 通过独立隐私评估 |
| **可及性** | 价格、多语言、无障碍 | 符合 WCAG 2.1 AA |

此外建议引入**临床内容审查委员会**（至少含一名持证催眠治疗师、一名精神科医师、一名临床心理学家）对脚本库进行逐条审查，特别关注：暗示的可证伪性（避免"治愈""根治"等绝对化表述）、对特定人群（孕产妇、癫痫、PTSD）的禁忌标注。

## BE.4 VR / AR 催眠的技术架构与临床应用

### BE.4.1 技术架构

**采集层**：头显（6DoF）、手柄/手势识别、可选眼动追踪、可选脑电（EEG）/皮电（EDA）/心率变异性（HRV）可穿戴。

**渲染层**：
- 场景引擎（Unity/Unreal）支持 90 fps 以上渲染，**避免低于 75 fps 引发晕动症**；
- 360° 全景视频 + 空间音频（Ambisonics）双轨方案：高保真场景用全景视频（成本低、真实感强），交互性场景用实时 3D；
- 光照与色彩遵循循证色彩心理学（蓝绿调降低唤醒、暖调用于创伤后重建）。

**交互与自适应层**：
- **生物反馈驱动的自适应场景**：HRV 降低或 EDA 升高 → 场景自动"退火"（缩小刺激、降低语速、引入安全意象）；
- 治疗师控制台（clinician console）：在混合式（therapist-led VR）模式下，治疗师可实时调整场景参数、投放意象提示、看到患者生理曲线；
- 会话编排器（session orchestrator）：管理诱导—深化—治疗—唤醒的场景状态机，异常时强制回到"安全屋"场景。

**数据层**：本地加密缓存 + 增量上云；生理数据时间戳与场景事件对齐，支持事后复盘与疗效建模。

### BE.4.2 临床应用

1. **疼痛管理**：VR 催眠用于烧伤换药、牙科操作、分娩镇痛、慢性疼痛。SnowWorld（华盛顿大学）等经典案例证明沉浸式意象可降低急性疼痛主观评分 35%–50%；叠加催眠暗示后效应进一步增强。
2. **焦虑与恐惧**：社交焦虑的虚拟演讲厅、飞行恐惧的机舱、幽闭恐惧的 MRI 模拟——VR 提供**可控的暴露层级**，催眠暗示增强自我效能感。
3. **PTSD 与创伤处理**：在稳定化充分的前提下，用 VR 呈现创伤相关安全可控场景，配合催眠的解离化技术（如"安全地带""观察者视角"）进行处理。须由受过创伤专门训练的治疗师执行。
4. **肿瘤与姑息治疗**：化疗期间的意象放松、临终关怀的"生命回顾"VR 场景，显著降低治疗期焦虑与疼痛用药量。
5. **儿科**：术前焦虑的"魔法森林"诱导、静脉穿刺时的注意力转移型催眠，儿童接受度高。
6. **康复**：卒中后运动想象（motor imagery）结合 VR 反馈，催眠深化提高意象清晰度与皮层激活水平。

### BE.4.3 局限与风险

- 晕动症（约 5%–15% 用户），须提供纯音频替代路径；
- 幽闭型设备不适、眼镜用户佩戴问题；
- 高情绪唤起场景须设置"**紧急退出（panic button）**"，一键回到中性场景并暂停会话；
- 内容更新的临床审核滞后风险（设计迭代 ≠ 临床验证迭代）；
- 成本与卫生（多人使用的头显清洁消毒规范）。

## BE.5 AI 驱动的个性化催眠系统

### BE.5.1 个性化维度与建模

个性化的目标是解决"同一种脚本对不同来访者效果差异巨大"的问题。可建模的维度：

1. **特质层**：催眠感受性（SHSS:C / HGSHS:A 的预测替代指标）、吸收（absorption）倾向、意象生动性（VVIQ）、语言风格（具体型/抽象型）、依恋类型。
2. **状态层**：当次会话前的压力水平、睡眠质量、情绪效价、动机水平。
3. **反应层**：历史会话中的实时反应（呼吸变慢速率、心率下降幅度、退出点、事后评分）。
4. **偏好层**：语音性别/音色、背景声、时长、意象主题、是否使用直接暗示。

**建模管线**：
```
多源数据 → 特征工程 → 元学习/多臂老虎机（contextual bandit）
        → 脚本要素推荐（诱导类型 × 深化技术 × 暗示框架 × 场景）
        → 会话后疗效反馈 → 模型更新
```
冷启动阶段采用**规则 + 问卷驱动**；数据充足后切换到**上下文老虎机**，在"利用已知最优"与"探索新组合"之间取得平衡。

### BE.5.2 生成式 AI 的角色与边界

**可承担的角色**：
- 脚本草稿生成（基于临床模板 + 个体参数）；
- 意象描述的本地化改写；
- 会话总结与治疗笔记辅助；
- 对话式预访谈（收集病史、禁忌筛查问卷的自然语言化）；
- 实时语速/停顿的自适应调整（合成语音层面）。

**不可逾越的边界**：
- **不得替代治疗师做出诊断、风险分级或危机决策**；
- **不得在无临床模板约束下自由生成治疗性暗示**（防止幻觉、不当暗示、文化冒犯）；
- 生成内容必须经过**规则引擎 + 临床过滤器 + 治疗师可审阅**的三级把关；
- 对来访者透明：明确告知"您的个性化脚本由 AI 辅助生成、经治疗师审核"。

### BE.5.3 评估指标

- 个性化增益（personalization gain）：相对固定脚本的效应量提升；
- 不当内容率（unsafe suggestion rate）：目标 < 0.1%，且全部被过滤器拦截；
- 人机一致性：临床专家对 AI 脚本的质量评分（≥4/5）；
- 可解释性：每条推荐须给出可读理由（"因您的 VVIQ 分数偏高，采用高细节视觉意象"）。

## BE.6 数字疗法（DTx）框架下的催眠

### BE.6.1 DTx 的定义与监管路径

数字疗法指**经临床验证、以软件驱动的循证治疗干预**，用于预防、管理或治疗疾病。其区别于普通健康 App 的核心是：循证、可审批、可处方、可报销。

各主要监管体系：
- **美国 FDA**：De Novo 分类、510(k)（有实质等同器械时）、Breakthrough Device 通道；代表产品 reSET（物质使用障碍）、Somryst/ Pear Therapeutics（慢性失眠，CBT-I 软件）。
- **欧盟 CE（MDR）**：作为医疗器械软件（SaMD）分类，Class IIa 起。
- **德国 DiGA（"数字疗法法案"，DVG）**：快速准入 + 医保报销路径，Fast-Track 12 个月临时准入，需在真实世界研究中证明"医疗效用"。
- **日本**：先驱审查制度（Sakigake）与部分产品纳入医保。
- **中国**：尚无独立 DTx 类别，实践中按**医疗器械软件（SaMD）**注册（如"处方数字疗法"试点），或以"互联网医院 + 慢病管理"模式落地；须遵守《医疗器械软件注册审查指导原则》与 AI 医疗器械相关规范。

### BE.6.2 催眠 DTx 的产品定位

可开发的催眠 DTx 方向（按证据成熟度排序）：

1. **慢性失眠（首选适应证）**：催眠与 CBT-I 融合，或催眠作为 CBT-I 的增效模块。失眠是 DTx 赛道证据最充分、监管路径最清晰的适应证。
2. **广泛性焦虑 / 压力相关障碍**：自我催眠程序 + HRV 生物反馈。
3. **慢性疼痛（腰背痛、纤维肌痛、IBS）**：作为阿片类药物减量的辅助干预。
4. **围手术期焦虑与急性疼痛**：术前使用、术中（在麻醉配合下）与术后康复。
5. **肠易激综合征（IBS）**：内脏高敏感的暗示调节，已有较好的催眠 RCT 基础（如 Northumbria/Gut-directed hypnosis 传统）。
6. **肿瘤相关症状群**：疼痛、失眠、恶心、癌因性疲乏。
7. **儿童功能性腹痛 / 夜尿**：亲子共同使用的版本。

### BE.6.3 临床试验设计要点

- **对照选择**：等待名单对照 → 主动对照（放松音频、健康教育、假 App）→ 非劣效对照（线下催眠）。监管级申报通常要求**主动对照 + 盲法评估者**。
- **终点**：主要终点采用监管认可的量表（如 ISI 失眠严重程度指数、VAS 疼痛、PHQ-9/GAD-7）；同时报告依从性与功能改善（工作/社会功能）。
- **真实世界证据（RWE）**：DTx 的一大优势是可持续采集使用数据。设计上应支持**单病例随机对照试验（N-of-1）**与阶梯式楔形（stepped wedge）设计，用于上市后疗效证明与报销谈判。
- **样本与统计**：考虑到数字干预的高脱落率，样本量应预留 20%–30% 缓冲；主要分析采用意向性分析（ITT）+ 混合效应模型。
- **随访**：至少 3 个月、理想 6–12 个月的持续效应随访。

### BE.6.4 商业与实施

- **支付模式**：按疗效付费（outcome-based pricing）优于按下载量；德国 DiGA 的"临时报销 + RWE 验证"模式值得借鉴。
- **医生采纳**：提供处方入口（EHR 集成）、患者进展仪表盘、可一键中止的医师控制台。
- **混合照护（blended care）**：产品承载 70% 的常规剂量，治疗师聚焦高价值干预（评估、危机、难点个案），显著提升服务产能。

## BE.7 远程催眠的循证证据

### BE.7.1 直接证据

- **远程催眠 vs. 面对面催眠的非劣效性**：多项小样本 RCT 与对照研究显示，视频引导催眠在**疼痛、焦虑、IBS 症状**上的效应量与面对面催眠相当（组间差异多在 g < 0.2 且统计不显著）。COVID 期间的快速转型研究进一步证实了远程交付的可行性与可接受性（患者满意度 ≥ 4/5）。
- **儿童与青少年**：远程催眠用于头痛、功能性腹痛的研究提示疗效保留良好，家长在场的模式提高了安全性。
- **肿瘤与围手术期**：视频催眠在术前焦虑与术后镇痛方面的小样本 RCT 提示中等效应（g ≈ 0.5–0.7），且阿片类用量下降趋势一致。

### BE.7.2 数字化/自助催眠的证据

- **音频自助催眠**：在失眠、考试焦虑、轻中度压力人群中，预录催眠音频的效应量多在 g = 0.3–0.6，优于无干预与假音频，与渐进式肌肉放松相当或略优。
- **App 形式的催眠/放松干预**：多项 RCT 显示数字干预在失眠（ISI 改善 3–6 分）与焦虑（GAD-7 改善 2–4 分）上具临床意义；含催眠成分的方案在**入睡潜伏期**与**夜间觉醒**上改善尤为一致。
- **VR 催眠**：急性疼痛的效应量较大（g ≈ 0.7–1.2），慢性疼痛与焦虑的效应量中等；多数研究样本量偏小、随访偏短，需更大规模确证。

### BE.7.3 证据分级小结

| 干预形式 | 适应证 | 证据等级（GRADE） | 备注 |
|---|---|---|---|
| 远程视频催眠 | 慢性疼痛、IBS、焦虑 | 中等 | 非劣效于面对面 |
| 音频自助催眠 | 失眠、考试焦虑 | 中等 | 成本低、可扩展 |
| 催眠 App | 失眠、压力 | 低–中等 | 依从性是关键调节变量 |
| VR 催眠 | 急性疼痛、术前焦虑 | 中等 | 效应量大，样本小 |
| 催眠 + 生物反馈 | 高血压、焦虑 | 低 | 需更多 RCT |
| AI 个性化催眠 | — | 极低/新兴 | 处于早期验证阶段 |

### BE.7.4 机制层面的发现

远程与面对面催眠在**主观深度评分、生理放松指标（HRV 提升、皮电下降）、暗示响应率**上无系统性差异；但以下因素会削弱远程效果：网络延迟破坏语言节奏、治疗师难以捕捉细微生理线索（如呼吸暂停、微表情）、居家环境干扰。**佩戴耳机、独处环境、治疗联盟评分（WAI-SR ≥ 60）**是远程疗效的正向调节变量。

## BE.8 数字催眠的伦理与隐私保护

### BE.8.1 核心伦理原则

1. **不伤害（Non-maleficence）**：任何数字化催眠产品必须内置安全护栏（见 BE.3.1 P5），并明确禁止用于诊断、替代紧急医疗、或在高危人群（急性自杀风险、精神病性症状）中独立使用。
2. **自主（Autonomy）**：来访者对暗示的接受权、随时退出权、数据删除权必须被产品机制保障，而非仅停留在协议文字。
3. **公正（Justice）**：数字鸿沟可能加剧健康不平等。设计上应提供低带宽模式、离线包、方言与低识字率人群的语音化界面；定价上避免"疗效只卖给富人"。
4. **透明（Transparency）**：AI 参与程度、推荐逻辑、数据用途须对用户可读可查；拒绝"黑箱疗效承诺"。
5. **责任（Accountability）**：明确产品失效、内容错误、AI 幻觉导致伤害时的**责任归属**（开发者、临床审核者、处方医生、平台方）。

### BE.8.2 隐私保护的技术与治理措施

**数据最小化**：只采集临床必需的数据。语音会话默认不录制；若录制用于质量改进，须单独同意且设定自动删除期限（建议 ≤90 天）。

**加密与隔离**：
- 传输层 TLS 1.3 + 端到端加密（会话内容）；
- 存储层 AES-256、密钥与数据分离管理（KMS/HSM）；
- 生理与行为数据去标识化 + 假名化（pseudonymization），标识符单独存储；
- 严格的角色访问控制（RBAC）与最小权限原则，所有访问留痕。

**敏感数据特别处理**：
- 催眠会话涉及**创伤、性经历、家庭关系**等高度敏感内容，应按最高敏感级别保护（可比照精神科心理治疗记录的特殊保护要求）；
- 生物识别数据（声纹、面部、脑电）在多国属**特殊类别个人信息**，需单独明示同意，禁止用于身份识别以外的二次用途（如保险定价、雇佣评估）；
- 儿童数据（COPPA、GDPR-K、中国未成年人网络保护条例）适用更严格标准。

**第三方生态治理**：对 SDK（分析、崩溃上报、推送）进行清单管理与年度审计；禁止向广告生态回传健康相关事件；跨境传输须符合当地法规（如中国的数据出境安全评估、欧盟的标准合同条款 SCC）。

**AI 特有风险**：
- 训练数据的代表性与偏见审计（避免对特定性别、口音、文化群体的暗示效果系统性偏差）；
- 生成内容的**对抗测试**（prompt injection、诱导不当暗示、越权建议）；
- 模型版本锁定与变更管理（regulatory change control）：模型升级须重新验证，避免"静默漂移"。

### BE.8.3 临床-技术联合治理机制

建议机构层面设立**数字催眠伦理与安全委员会（DESC）**，职责包括：
- 新脚本/新场景/新算法的临床前审查；
- 不良事件的月度复盘与产品迭代建议；
- 用户投诉与"数字知情同意"执行情况的抽查；
- 与监管机构（药监、网信、卫健）的合规对接；
- 年度透明度报告（不良事件数、数据请求响应、AI 干预次数）。

### BE.8.4 给临床工作者的十条速记

1. 远程不等于低风险，安全协议同等严格。
2. 网络中断预案 = 线下治疗的"停电预案"。
3. 唤醒程序永不省略，永不跳过。
4. 高危个案不交给纯自助产品。
5. 知情同意必须覆盖数据与 AI。
6. 录音录像必须单独同意、限期删除。
7. AI 可以写草稿，不能做决策。
8. 依从性是疗效的前提，先测依从再谈疗效。
9. 产品的退出路径与入口同样重要。
10. 当屏幕里的来访者比你更需要线下时，转介就是疗效。

## 本附录小结

催眠的数字化不是把脚本搬进手机，而是把**临床推理、安全边界与治疗关系**重新编码进技术系统。远程催眠在多个适应证上已显示与面对面干预相当的疗效；催眠 App 与 VR 催眠正在走向处方化与监管化；AI 个性化处于快速演进但需严格把关的阶段。未来五年，"混合式催眠照护（blended hypnosis care）"将成为主流形态：产品承担高频低强度的自我干预，治疗师聚焦高价值的临床判断与关系性工作，数据闭环持续优化两者的分工。

对于临床工作者，掌握本附录的技术规范、伦理框架与证据地图，是在数字时代安全、专业、可持续地开展催眠实践的必要条件。
