## 第一部分：基础理论篇

### 第1章 催眠学导论与学科定位

**学习目标：**
1. 能够给出催眠的多维度定义
2. 能够区分催眠与睡眠、冥想、引导想象
3. 理解催眠的主观体验特征
4. 了解催眠研究的常见误解及其澄清

**关键术语：** 意识改变状态（ASC）、暗示感受性、催眠感受性、吸收、解离

**核心要点：**
- 催眠是注意力聚焦+暗示响应增强的意识状态
- 催眠感受性呈正态分布，与意志力无关
- 催眠的神经机制可被脑影像技术测量

### 第2章 催眠的历史演进与流派

**学习目标：**
1. 描述催眠史上的关键人物和事件
2. 区分南锡学派与巴黎学派的观点
3. 理解艾瑞克森对现代临床催眠的贡献
4. 了解中国催眠发展的脉络

**关键术语：** 动物磁力、暗示理论、新分离理论、自然主义催眠

**核心要点：**
- 催眠经历了从神秘主义到科学的发展
- 艾瑞克森的自然主义方法改变了临床实践
- 催眠的科学基础由赫尔和希尔加德奠定

### 第3章 催眠的神经科学基础

**学习目标：**
1. 描述催眠态的关键脑区变化
2. 理解催眠镇痛的神经机制
3. 了解催眠感受性的神经标记物
4. 理解预测编码框架下催眠的机制

**关键术语：** 前扣带回（ACC）、默认模式网络（DMN）、执行控制网络（ECN）、突显网络（SN）

**核心要点：**
- 催眠涉及DMN活动降低、ECN模式改变
- 催眠镇痛有真实的神经生理基础
- 感受性的神经预测仍处于研究阶段

### 第4章 催眠心理学理论模型

**学习目标：**
1. 描述分离理论、社会认知理论、认知理论的核心观点
2. 比较各理论的优势和局限
3. 理解预测编码理论如何整合各理论
4. 了解当代整合模型

**关键术语：** 新分离理论、隐藏观察者、角色扮演理论、响应期望、预测编码

**核心要点：**
- 没有单一理论能完全解释催眠
- 预测编码提供了有前景的整合框架
- 临床实践需要多元理论视角

### 第5章 意识、暗示与催眠感受性

**学习目标：**
1. 理解催眠态的意识特征
2. 描述暗示的心理机制
3. 了解催眠感受性的测量方法
4. 理解影响催眠感受性的因素

**关键术语：** 暗示、催眠感受性、SHSS、吸收倾向、暗示感受性

**核心要点：**
- 催眠感受性存在稳定的个体差异
- 暗示响应受多因素影响
- 感受性可以通过训练适度提升

### 第10章 自我催眠与催眠训练

**学习目标：**

## 全书核心概念思维导图（文字版）

以"催眠"为中心，向外延伸六个主分支：

1. **基础理论** → 历史源流（流派代表人物）→ 理论模型（生理/心理/社会认知）→ 感受性与个体差异
2. **核心技术** → 导入技术（渐进/凝视/快速）→ 深化技术（数数/下沉/意象）→ 暗示设计（直接/间接/隐喻）→ 唤醒与收尾
3. **临床应用** → 行为习惯（戒烟、减重）→ 情绪与睡眠（焦虑、失眠）→ 疼痛管理 → 创伤与PTSD（稳定化优先）
4. **专题领域** → 自我催眠（教练法）→ 儿童青少年催眠（发展适配）→ 整合取向（催眠+CBT/ACT/EMDR）
5. **文化与背景** → 跨文化催眠 → 中国本土化实践
6. **伦理与规范** → 知情同意 → 胜任力边界 → 法律框架 → 转介与督导

**连接线索（贯穿全书）：**
- 纵向：理论→技术→应用→专题→伦理，层层递进（"为什么→怎么做→用在哪→谁能用→边界何在"）
- 横向：每个应用主题都同时触及技术选择、风险评估、文化适配三条主线
- 附录体系：M（临床速查）服务于第6-17章；O（学习指南）服务于全章；G（安全手册）为所有实践兜底

**复习建议：**先记住六个主分支名称，再逐支展开；每章末的练习题可作为分支末端的"叶子节点"自测锚点。
