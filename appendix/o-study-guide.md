# 附录O：全书学习指南

> 每章的学习目标、关键术语和核心要点速查。

---

## 第一部分：基础理论篇

### 第1章 催眠学导论与学科定位

**学习目标：**
1. 能够给出催眠的多维度定义
2. 能够区分催眠与睡眠、冥想、引导想象
3. 理解催眠的主观体验特征
4. 了解催眠研究的常见误解及其澄清

**关键术语：** 意识改变状态（ASC）、暗示感受性、催眠感受性、吸收、解离

**核心要点：**
- 催眠是注意力聚焦+暗示响应增强的意识状态
- 催眠感受性呈正态分布，与意志力无关
- 催眠的神经机制可被脑影像技术测量

### 第2章 催眠的历史演进与流派

**学习目标：**
1. 描述催眠史上的关键人物和事件
2. 区分南锡学派与巴黎学派的观点
3. 理解艾瑞克森对现代临床催眠的贡献
4. 了解中国催眠发展的脉络

**关键术语：** 动物磁力、暗示理论、新分离理论、自然主义催眠

**核心要点：**
- 催眠经历了从神秘主义到科学的发展
- 艾瑞克森的自然主义方法改变了临床实践
- 催眠的科学基础由赫尔和希尔加德奠定

### 第3章 催眠的神经科学基础

**学习目标：**
1. 描述催眠态的关键脑区变化
2. 理解催眠镇痛的神经机制
3. 了解催眠感受性的神经标记物
4. 理解预测编码框架下催眠的机制

**关键术语：** 前扣带回（ACC）、默认模式网络（DMN）、执行控制网络（ECN）、突显网络（SN）

**核心要点：**
- 催眠涉及DMN活动降低、ECN模式改变
- 催眠镇痛有真实的神经生理基础
- 感受性的神经预测仍处于研究阶段

### 第4章 催眠心理学理论模型

**学习目标：**
1. 描述分离理论、社会认知理论、认知理论的核心观点
2. 比较各理论的优势和局限
3. 理解预测编码理论如何整合各理论
4. 了解当代整合模型

**关键术语：** 新分离理论、隐藏观察者、角色扮演理论、响应期望、预测编码

**核心要点：**
- 没有单一理论能完全解释催眠
- 预测编码提供了有前景的整合框架
- 临床实践需要多元理论视角

### 第5章 意识、暗示与催眠感受性

**学习目标：**
1. 理解催眠态的意识特征
2. 描述暗示的心理机制
3. 了解催眠感受性的测量方法
4. 理解影响催眠感受性的因素

**关键术语：** 暗示、催眠感受性、SHSS、吸收倾向、暗示感受性

**核心要点：**
- 催眠感受性存在稳定的个体差异
- 暗示响应受多因素影响
- 感受性可以通过训练适度提升

## 第二部分：技术方法篇

### 第6章 催眠诱导技术全谱

**学习目标：**
1. 掌握至少3种标准催眠诱导技术
2. 能够根据来访者特征选择合适的诱导方式
3. 了解快速诱导和自然主义诱导的原理
4. 掌握诱导效果的评估方法

**关键术语：** 催眠诱导、凝视诱导、渐进放松、戴夫·埃尔曼快速诱导、自然主义催眠

### 第7章 深化与深化技术

**学习目标：**
1. 掌握至少4种深化技术
2. 理解催眠深度的测量方法
3. 能够根据临床需要调整催眠深度
4. 掌握过度深化的识别和处理

**关键术语：** 深化、递进式深化、分段法、催眠深度

### 第8章 催眠暗示的设计与实施

**学习目标：**
1. 掌握暗示设计的5个有效性原则
2. 区分直接暗示和间接暗示的使用场景
3. 能够设计后催眠暗示
4. 掌握暗示效果的评估方法

**关键术语：** 直接暗示、间接暗示、隐喻暗示、嵌入式命令、双重束缚

### 第9章 催眠唤醒与后催眠暗示

**学习目标：**
1. 掌握标准唤醒程序和唤醒变式
2. 理解唤醒困难的原因和处理方法
3. 能够设计有效的后催眠暗示
4. 理解催眠后现象及其处理

**关键术语：** 唤醒、后催眠暗示、催眠后健忘、锚定

### 第10章 自我催眠与催眠训练

**学习目标：**
1. 掌握自我催眠的5步标准程序
2. 能够教授来访者自我催眠技术
3. 掌握自我催眠的常见问题处理
4. 设计个性化的自我催眠练习方案

**关键术语：** 自我催眠、锚定技术、意象排练、安全地带

### 第11章 团体催眠与舞台催眠

**学习目标：**
1. 理解团体催眠与个体催眠的区别
2. 掌握团体催眠的组织和实施
3. 了解舞台催眠的伦理和安全要求
4. 掌握舞台催眠应急处理

**关键术语：** 团体催眠、舞台催眠、安全检查清单

## 第三部分：临床应用篇

### 第12章 催眠镇痛与疼痛管理

**学习目标：**
1. 理解催眠镇痛的神经机制
2. 掌握急性疼痛和慢性疼痛的催眠管理方案
3. 能够使用感觉替代、分离、重塑等镇痛技术
4. 理解催眠镇痛的循证证据等级

**关键术语：** 催眠镇痛、感觉替代、疼痛分离、HypnoBirthing

### 第13章 焦虑、恐惧与创伤处理

**学习目标：**
1. 掌握焦虑障碍的催眠治疗方案
2. 理解催眠暴露疗法的原理和步骤
3. 掌握PTSD阶段导向催眠治疗模型
4. 了解创伤处理的安全要求

**关键术语：** 催眠暴露、安全地带、情绪容器、创伤知情

### 第14章 催眠在心理治疗中的整合应用

**学习目标：**
1. 理解催眠与CBT整合的原理和方法
2. 掌握催眠与正念整合的技术
3. 了解催眠与叙事疗法的整合
4. 理解整合治疗的基本原则

**关键术语：** 认知行为催眠治疗（CBH）、正念催眠、叙事催眠

### 第15章 催眠在医学中的应用

**学习目标：**
1. 理解催眠在手术中的应用
2. 掌握IBS催眠治疗方案
3. 了解催眠在癌症治疗中的应用
4. 理解催眠在产科、皮肤科、牙科的应用

**关键术语：** 催眠镇静（Hypnosedation）、肠道定向催眠、HypnoBirthing

### 第16章 儿童与青少年催眠

**学习目标：**
1. 理解不同年龄段儿童的催眠适应
2. 掌握游戏化催眠技术
3. 了解儿童催眠的常见应用
4. 理解父母参与的原则和方法

**关键术语：** 游戏化诱导、意象技术、发展适应性

### 第17章 成瘾行为与习惯改变

**学习目标：**
1. 理解成瘾的催眠治疗框架
