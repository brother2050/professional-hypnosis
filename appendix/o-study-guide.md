## 第一部分：基础理论篇

### 第1章 催眠学导论与学科定位　⭐核心

**⭐ 必须掌握：**
1. 能够给出催眠的多维度定义
2. 能够区分催眠与睡眠、冥想、引导想象

**◐ 理解即可：**
3. 理解催眠的主观体验特征

**○ 了解即可：**
4. 了解催眠研究的常见误解及其澄清

**关键术语：** 意识改变状态（ASC）、暗示感受性、催眠感受性、吸收、解离

**核心要点：**
- 催眠是注意力聚焦+暗示响应增强的意识状态
- 催眠感受性呈正态分布，与意志力无关
- 催眠的神经机制可被脑影像技术测量

### 第2章 催眠的历史演进与流派　○拓展（背景）

**◐ 理解即可：**
1. 理解艾瑞克森对现代临床催眠的贡献

**○ 了解即可：**
2. 描述催眠史上的关键人物和事件
3. 区分南锡学派与巴黎学派的观点
4. 了解中国催眠发展的脉络

**关键术语：** 动物磁力、暗示理论、新分离理论、自然主义催眠

**核心要点：**
- 催眠经历了从神秘主义到科学的发展
- 艾瑞克森的自然主义方法改变了临床实践
- 催眠的科学基础由赫尔和希尔加德奠定

### 第3章 催眠的神经科学基础　◐重要

**◐ 理解即可：**
1. 描述催眠态的关键脑区变化
2. 理解催眠镇痛的神经机制

**○ 了解即可：**
3. 了解催眠感受性的神经标记物
4. 理解预测编码框架下催眠的机制

**关键术语：** 前扣带回（ACC）、默认模式网络（DMN）、执行控制网络（ECN）、突显网络（SN）

**核心要点：**
- 催眠涉及DMN活动降低、ECN模式改变
- 催眠镇痛有真实的神经生理基础
- 感受性的神经预测仍处于研究阶段

### 第4章 催眠心理学理论模型　⭐核心

**⭐ 必须掌握：**
1. 描述分离理论、社会认知理论、认知理论的核心观点
2. 比较各理论的优势和局限

**◐ 理解即可：**
3. 理解预测编码理论如何整合各理论

**○ 了解即可：**
4. 了解当代整合模型

**关键术语：** 新分离理论、隐藏观察者、角色扮演理论、响应期望、预测编码

**核心要点：**
- 没有单一理论能完全解释催眠
- 预测编码提供了有前景的整合框架
- 临床实践需要多元理论视角

### 第5章 意识、暗示与催眠感受性　⭐核心

**⭐ 必须掌握：**
1. 描述暗示的心理机制

**◐ 理解即可：**
2. 理解催眠态的意识特征
3. 理解影响催眠感受性的因素

**○ 了解即可：**
4. 了解催眠感受性的测量方法（实操用附录A量表即可）

**关键术语：** 暗示、催眠感受性、SHSS、吸收倾向、暗示感受性

**核心要点：**
- 催眠感受性存在稳定的个体差异
- 暗示响应受多因素影响
- 感受性可以通过训练适度提升

## 全书核心概念思维导图（文字版）

以“催眠”为中心，向外延伸六个主分支（→ 后为子分支，括号内为对应章节）：

1. **基础理论（第0-5章）**
   ├─ 历史源流 → 动物磁力（梅斯梅尔）→ 暗示理论（布雷德/南锡/巴黎之争）→ 实验催眠（赫尔/希尔加德）→ 艾瑞克森自然主义（第2章）
   ├─ 理论模型 → 分离理论/新分离理论 → 社会认知理论 → 预测编码/自由能框架 → 多层面互补观（第0、4章）
   ├─ 神经机制 → DMN↓/ECN模式改变 → 前扣带回-疼痛调节 → 镇痛通路（第3章）
   └─ 感受性与个体差异 → 定义与测量（SHSS/HGSHS）→ 正态分布→ 影响因素 → 适度可提升（第5章）
