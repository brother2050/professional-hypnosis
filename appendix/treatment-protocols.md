# 治疗协议模板集

> 常见问题的治疗协议模板；所有协议均以医学评估与知情同意为前置，不替代个体化临床判断。安全红线见[DISCLAIMER](../DISCLAIMER.md)与[附录G](g-safety-manual.md)。

> **🔗 前后衔接**：前置——先完成医学评估、签署知情同意（表单见[实用工具集](practical-tools.md)）；本篇解决——具体问题的分阶段治疗协议怎么选、怎么排期、到什么判据调整；深入——各技术步骤，想深入可看[第6章](../chapters/06-induction-techniques.md)至[第10章](../chapters/10-self-hypnosis.md)，执行中的失败分支，想深入可看[附录I](i-failure-difficulties.md)。
> - **场景关键词**：治疗协议｜疗程安排｜疼痛｜焦虑｜PTSD｜儿童｜团体｜失眠｜运动表现

> 📌 **使用总则**：①协议是骨架，个体化是血肉——每个“____”都要换成个案信息（填写示例见各模板）；②“示意”数字仅供格式参考；③执行到调整节点时，对照下方“通用判据与失败分支表”决定继续、改方案还是转介。

**通用判据与失败分支（适用于本文件所有协议）：**

| 触发信号（看到什么） | 动作（做什么） | 判据（做到什么程度） |
|------|------|------|
| 每3次治疗复评一次主诉评分 | 计算下降幅度并与目标对照 | 下降≥25%→继续现方案；下降<25%→先换暗示策略；再3次仍<25%→回个案概念化或转介 |
| 家庭作业完成率低于一半 | 当场找原因（难度/意义/时间），改微作业 | 连续2周每日3分钟能完成→再加量 |
| 症状清单变多、旧症状缓解新症状出现 | 做功能分析；家庭两次回避谈“康复后怎么办”→约一次家庭访谈（想深入可看[附录I](i-failure-difficulties.md)案例6） | 目标收窄为“带着症状恢复功能”，并写入下次目标栏 |
| 出现解离、闪回、持续情绪失控 | 停止一切创伤加工，回到稳定化（[附录G](g-safety-manual.md)） | 稳定化连续2次达标才恢复原计划，否则转介精神科 |

## 疼痛管理治疗协议

### 慢性疼痛催眠治疗协议

**患者选择标准：**
1. 慢性疼痛（持续>3个月）
2. 催眠感受性中等以上（SHSS:C ≥5分）
3. 无严重精神疾病
4. 愿意参与催眠治疗
5. 能够进行自我催眠练习

**排除标准：**
1. 严重精神病性症状
2. 未控制的癫痫
3. 严重认知障碍
4. 对催眠的极端恐惧或拒绝
5. 物质滥用（活动期）

**治疗方案：**

**第1-2周：评估与建立**
- 全面疼痛评估
- 催眠感受性评估
- 治疗目标设定
- 安全地带建立
- 自我催眠入门

**第3-4周：技能培养**
- 渐进放松深化
- 呼吸催眠训练
- 身体扫描技术
- 感觉觉察训练
- 疼痛日记记录

**第5-6周：疼痛管理技术**
- 疼痛分离技术
- 感觉替代技术
- 疼痛重塑技术
- 疼痛控制感建立
- 自我镇痛训练

**第7-8周：认知重构**
- 疼痛认知评估
- 灾难化思维识别
- 认知重构暗示
- 积极自我对话
- 接纳与承诺

**第9-10周：情绪处理**
- 伴随情绪识别
- 情绪调节暗示
- 悲伤和损失处理
- 愤怒和挫折处理
- 希望和意义建立

**第11-12周：功能恢复与维持**
- 活动恢复暗示
- 功能目标设定
- 复发预防策略
- 长期自我管理计划
- 随访计划制定

**评估时间点：**
- 治疗前基线
- 每次治疗前后
- 治疗中期（第6周）
- 治疗结束时
- 随访期（1个月、3个月、6个月）

**效果评估指标：**
- 疼痛强度（VAS/NRS）
- 功能障碍（ODI/DASH）
- 情绪状态（GAD-7/PHQ-9）
- 睡眠质量（PSQI）
- 生活质量（SF-36）
- 患者满意度

**执行提示与常见填错：** ①“第5-6周疼痛管理技术”之前若安全地带未建立（判据：来访者能独立复现安全地带≥2分钟），顺延一周，不抢进度；②疼痛个案出现新发红旗症状（发热、体重下降、夜间痛醒）→暂停协议转医学评估；③“减少药物”栏只写“遵医嘱”，不写具体减药计划。

## 焦虑障碍治疗协议

### 广泛性焦虑障碍催眠治疗协议

**患者选择标准：**
1. 符合GAD诊断标准
2. 催眠感受性中等以上
3. 无严重精神疾病
4. 愿意参与催眠治疗

**治疗方案：**

**第1-3周：建立与稳定**
- 全面评估和个案概念化
- 安全地带建立
- 基础放松和自我催眠训练
- 心理教育

**第4-6周：技能培养**
- 认知重构催眠
- 情绪调节暗示
- 注意力训练暗示
- 身体放松深化

**第7-9周：深度处理**
- 焦虑根源探索
- 核心信念重构
- 情绪释放处理
- 自信建立暗示

**第10-12周：整合与维持**
- 未来导向暗示
- 复发预防策略
- 长期自我管理计划
- 随访计划制定

**评估指标：**
- GAD-7焦虑量表
- PHQ-9抑郁量表
- PSQI睡眠量表
- 自我效能感量表
- 功能评估

**执行提示与常见填错：** ①第7-9周“焦虑根源探索”属深度工作，前提判据：GAD-7较基线下降且稳定化技能达标，否则延长第4-6周；②PHQ-9第9题（自伤意念）任一次≥1分→当场停催眠加工、不独留，当面做安全计划（识别警告信号、内部应对策略、两个可拨打的人名+电话、环境安全化），按三档现场分流：有计划/手段/意图任一 → 联系监护人 + 精神科急诊（120/110）；有想法无计划 → 48 小时内精神科门诊 + 每日签到；仅被动意念 → 记录原话与风险因素、下次会谈提前至 ≤1 周。分级判定对照[实用工具集](practical-tools.md)危机处理分流表；③“心理教育”不写内容就归档→至少记录讲了哪三个点（什么是焦虑、呼吸练习怎么做、作业为什么重要）。

## 创伤治疗协议

### PTSD催眠治疗协议

**患者选择标准：**
1. 符合PTSD诊断标准
2. 催眠感受性中等以上
3. 无活动性精神病性症状
4. 有足够的稳定化资源
5. 愿意参与催眠治疗

**治疗方案：**

**阶段1：稳定化与资源建立（第1-6周）**
1. 全面评估
2. 安全地带建立和强化
3. 情绪调节技能训练
4. 自我催眠训练
5. 内在资源建立
6. 解离症状管理

**阶段2：创伤记忆处理（第7-12周）**
1. 催眠暴露治疗
2. 认知重构
3. 情感加工
4. 记忆整合
5. 身体感觉处理
6. 解离症状管理

**阶段3：整合与重建（第13-16周）**
1. 生命故事重写
2. 未来导向暗示
3. 关系修复暗示
4. 复发预防策略
5. 长期管理计划
6. 随访计划制定

**安全措施（逐条可判）：**
1. 进入阶段2的判据：来访者能在5分钟内独立进入安全地带并说出3个感官细节，连续2次会谈达标；未达标→延长阶段1，不碰创伤材料
2. 情绪窗口判据：主观困扰（0-10）在3-7分区间工作；升到8分以上→回到稳定化；低于2分→不用强情绪唤起技术
3. 危机预案：书面写明预警信号（失眠加重、闪回变频、自伤意念）、2个可拨打的联系人、就近精神科急诊地址
4. 协调：与转介方/精神科每4周互通一次信息（先取得来访者书面同意）
5. 进展评估：每3次用PCL-5或自评复测；连续两次无下降→回到阶段1或转介（分流规则见文首通用判据表）

## 儿童催眠治疗协议

### 儿童焦虑催眠治疗协议

**患者选择标准：**
1. 年龄6-12岁
2. 符合焦虑障碍诊断
3. 愿意参与催眠游戏
4. 父母同意并支持

**治疗方案：**

**第1-2周：建立关系**
- 游戏化评估
- 建立信任关系
- 父母教育
- 安全地带建立（游戏化）

**第3-4周：技能培养**
- 呼吸游戏
- 想象游戏
- 放松游戏
- 自信游戏

**第5-6周：问题处理**
- 恐惧游戏暴露
- 焦虑管理游戏
- 问题解决游戏
- 社交技能游戏

**第7-8周：巩固与泛化**
- 成功经验强化
- 技能泛化训练
- 父母培训
- 长期维护计划

**父母参与：**
- 每次治疗前后各5分钟会谈（只谈安排与家庭观察，不披露孩子单独表述的内容，安全例外除外）
- 家庭练习给一张图示清单（如“睡前3个气球呼吸”），每次不超过1个动作
- 每月一次书面进展反馈（写行为变化，不写诊断标签）
- 首次会谈即给危机处理指导：发现自伤/伤人言行时的3个步骤与本地心理援助热线

**执行提示与常见填错：** ①儿童协议总时长6-8周，单次30-45分钟，超时即收尾（注意时长比成人短一半）；②把父母的治疗期待直接当儿童目标→必须用儿童自己的话重写目标；③“恐惧游戏暴露”前未与儿童约定停止信号（如举手）→先约定再做。

## 自我催眠训练协议

### 4周自我催眠训练方案

**第1周：基础训练**
- 每日练习：10分钟
- 内容：
  1. 呼吸催眠（3分钟）
  2. 身体扫描（4分钟）
  3. 安全地带想象（3分钟）

**第2周：深化训练**
- 每日练习：15分钟
- 内容：
  1. 呼吸催眠（3分钟）
  2. 渐进放松（5分钟）
  3. 倒数深化（4分钟）
  4. 安全地带想象（3分钟）

**第3周：暗示训练**
- 每日练习：15分钟
- 内容：
  1. 呼吸催眠（3分钟）
  2. 渐进放松（4分钟）
  3. 倒数深化（3分钟）
  4. 自我暗示（5分钟）

**第4周：应用训练**
- 每日练习：15-20分钟
- 内容：
  1. 呼吸催眠（3分钟）
  2. 渐进放松（4分钟）
  3. 倒数深化（3分钟）
  4. 问题导向暗示（5-10分钟）

**评估：**
- 每日练习记录
- 每周自我评估
- 第4周综合评估
- 后续维护计划

**完成判据与失败分支：** 判据——第4周能独立完成15-20分钟全程、每周≥5天；失败分支——连续2周做不到→退回第2周内容，改为每日3分钟微作业（[附录I](i-failure-difficulties.md)“微作业化”），仍做不到→改听引导音频，不硬撑。

## 协议：失眠催眠治疗协议

**适用对象：** 非器质性失眠（入睡困难、睡眠维持困难、早醒）来访者，已排除睡眠呼吸暂停等器质性疾病。

**治疗目标：**
1. 缩短入睡潜伏期（目标：≤30分钟）
2. 减少夜间觉醒次数，提高睡眠连续性
3. 重建“床=睡眠”的条件反射，降低睡前觉醒水平

**评估要点：**
- 睡眠日记（至少记录1周基线数据）
- 失眠严重程度指数（ISI）
- 排查咖啡因/酒精/药物使用、昼夜节律问题、共病焦虑抑郁

**治疗结构（6-8次）：**

| 阶段 | 次数 | 内容 |
|------|------|------|
| 评估与概念化 | 第1次 | 睡眠评估、心理教育、睡眠卫生指导、建立目标 |
| 放松与导入训练 | 第2-3次 | 渐进式放松结合催眠导入，教授自我催眠入睡法 |
| 睡眠重建 | 第4-5次 | 催眠暗示重建床与睡眠联结；处理“怕失眠”的预期焦虑；矛盾意向技术 |
| 巩固与复发预防 | 第6-8次 | 强化自我催眠，制定睡眠维护计划，处理复发信号 |

**核心催眠技术：**
1. **身体沉重温暖诱导：** 从四肢沉重感入手，配合呼吸计数（“吸气…呼气，让身体更沉一点”）
2. **阶梯下行意象：** 逐级下楼梯，每级伴随“更深、更放松、更接近睡眠”暗示
3. **安全岛睡眠意象：** 引导至舒适睡眠场景（柔软的床、温暖的被窝、安全的房间），允许自然入睡
4. **认知解离暗示：** “念头来了又走，像云飘过，不需要跟随，只需要回到呼吸和沉下去的感觉”
5. **睡后暗示：** “今晚你会在合适的时间自然入睡，中途醒来也能轻松回到睡眠”

**注意事项：**
- 不与刺激控制、睡眠限制等CBT-I行为成分冲突，可联合使用
- 避免在床上做催眠练习（防止破坏床与睡眠的联结），练习在椅子上进行
- 白天嗜睡严重者先评估睡眠不足，再调整治疗节奏
- 持续失眠伴情绪问题者建议联合精神科评估

**家庭作业：** 每日睡前自我催眠练习（15-20分钟）、睡眠日记记录、固定起床时间。

**填写示例（示意）：** 睡眠日记只记5项——上床时间、估计入睡时间、夜间觉醒次数、起床时间、总睡眠时长；目标写“入睡潜伏期 60→30分钟”。

**常见填错：** ①在床上做自我催眠练习（破坏“床=睡眠”联结，改在椅子上）；②睡眠日记记成流水账，越记越焦虑；③把“允许自然入睡”暗示写成“必须睡着”（反向暗示，加重预期焦虑）。

## 协议：运动表现提升协议

**适用对象：** 运动员及运动爱好者，用于比赛/训练中的表现提升、状态调整与心理技能训练。非心理障碍治疗，属表现促进范畴。

**治疗目标：**
1. 提升动作执行的稳定性与流畅性（自动化“zone”状态）
2. 管理赛前焦虑与唤醒水平，达到最佳功能区
3. 增强自信、专注力与逆境心理韧性

**评估要点：**
- 运动项目、专项动作特征与常见失误模式
- 竞赛焦虑量表（CSAI-2R）与最佳唤醒水平评估
- 既往“最佳表现”体验的详细回忆（用于锚定）

**治疗结构（4-6次）：**

| 阶段 | 次数 | 内容 |
|------|------|------|
| 评估与目标设定 | 第1次 | 运动情境分析、表现目标具体化、基线心理测评 |
| 催眠与意象训练 | 第2-3次 | 自我催眠导入、成功意象演练、最佳状态锚定 |
| 情境模拟 | 第4-5次 | 催眠下模拟比赛压力情境、抗干扰与失误后复位训练 |
| 赛前整合 | 第6次 | 制定赛前心理准备流程（routine）、便携锚点与自我暗示口令 |

**核心催眠技术：**
1. **成功意象演练：** 以第一人称、实时速度反复“观看”完美动作执行，加入本体感觉（肌肉发力感、节奏、呼吸）
2. **最佳状态锚定：** 在催眠中唤回巅峰体验，于高峰时刻设置触觉锚点（如拇指与食指相扣），赛前触发
3. **触发词训练：** 建立关键词（如“稳”、“流动”）快速唤起专注与放松并存的竞技状态
4. **压力免疫暗示：** 催眠下模拟落后、失误、观众噪音等情境，练习“一次呼吸复位”——失误后单次深呼吸即清零
5. **过程聚焦暗示：** 将注意力锚定在动作过程而非结果（“只看这一球、这一次动作、这一口气”）

**注意事项：**
- 明确区分表现促进与心理障碍治疗；合并焦虑障碍/进食障碍等需另行评估转介
- 意象训练强度渐进，避免过度“预演”导致训练替代（imagery substitution）
- 与教练/体能团队的配合需经来访者授权，注意保密边界
- 比赛周期结合：赛季中以简短触发技术为主，休赛期可深入处理

**家庭作业：** 每日10-15分钟意象演练、赛前心理准备流程演练、训练日志记录唤醒水平与“流畅感”评分。

**填写示例（示意）：** 触发词写“稳”（单字，好默念）；训练日志每行：项目、唤醒水平（0-10）、流畅感（0-10）、一句话备注。

**常见填错：** ①比赛前48小时还做深度处理（改为只用触发词，避免疲劳与波动）；②意象只“看”不“感觉”（要加肌肉发力感、节奏、呼吸）；③合并焦虑障碍/进食障碍仍按表现促进协议做→先精神科评估（红线：不替代医疗）。
