## 疼痛管理治疗协议

### 慢性疼痛催眠治疗协议

**患者选择标准：**
1. 慢性疼痛（持续>3个月）
2. 催眠感受性中等以上（SHSS:C ≥5分）
3. 无严重精神疾病
4. 愿意参与催眠治疗
5. 能够进行自我催眠练习

**排除标准：**
1. 严重精神病性症状
2. 未控制的癫痫
3. 严重认知障碍
4. 对催眠的极端恐惧或拒绝
5. 物质滥用（活动期）

**治疗方案：**

**第1-2周：评估与建立**
- 全面疼痛评估
- 催眠感受性评估
- 治疗目标设定
- 安全地带建立
- 自我催眠入门

**第3-4周：技能培养**
- 渐进放松深化
- 呼吸催眠训练
- 身体扫描技术
- 感觉觉察训练
- 疼痛日记记录

**第5-6周：疼痛管理技术**
- 疼痛分离技术
- 感觉替代技术
- 疼痛重塑技术
- 疼痛控制感建立
- 自我镇痛训练

**第7-8周：认知重构**
- 疼痛认知评估
- 灾难化思维识别
- 认知重构暗示
- 积极自我对话
- 接纳与承诺

**第9-10周：情绪处理**
- 伴随情绪识别
- 情绪调节暗示
- 悲伤和损失处理
- 愤怒和挫折处理
- 希望和意义建立

**第11-12周：功能恢复与维持**
- 活动恢复暗示
- 功能目标设定
- 复发预防策略
- 长期自我管理计划
- 随访计划制定

**评估时间点：**
- 治疗前基线
- 每次治疗前后
- 治疗中期（第6周）
- 治疗结束时
- 随访期（1个月、3个月、6个月）

**效果评估指标：**
- 疼痛强度（VAS/NRS）
- 功能障碍（ODI/DASH）
- 情绪状态（GAD-7/PHQ-9）
- 睡眠质量（PSQI）
- 生活质量（SF-36）
- 患者满意度

## 焦虑障碍治疗协议

### 广泛性焦虑障碍催眠治疗协议

**患者选择标准：**
1. 符合GAD诊断标准
2. 催眠感受性中等以上
3. 无严重精神疾病
4. 愿意参与催眠治疗

**治疗方案：**

**第1-3周：建立与稳定**
- 全面评估和个案概念化
- 安全地带建立
- 基础放松和自我催眠训练
- 心理教育

**第4-6周：技能培养**
- 认知重构催眠
- 情绪调节暗示
- 注意力训练暗示
- 身体放松深化

**第7-9周：深度处理**
- 焦虑根源探索
- 核心信念重构
- 情绪释放处理
- 自信建立暗示

**第10-12周：整合与维持**
- 未来导向暗示
- 复发预防策略
- 长期自我管理计划
- 随访计划制定

**评估指标：**
- GAD-7焦虑量表
- PHQ-9抑郁量表
- PSQI睡眠量表
- 自我效能感量表
- 功能评估

## 创伤治疗协议

### PTSD催眠治疗协议

**患者选择标准：**
1. 符合PTSD诊断标准
2. 催眠感受性中等以上
3. 无活动性精神病性症状
4. 有足够的稳定化资源
5. 愿意参与催眠治疗

**治疗方案：**

**阶段1：稳定化与资源建立（第1-6周）**
1. 全面评估
2. 安全地带建立和强化
3. 情绪调节技能训练
4. 自我催眠训练
5. 内在资源建立
6. 解离症状管理

**阶段2：创伤记忆处理（第7-12周）**
1. 催眠暴露治疗
2. 认知重构
3. 情感加工
4. 记忆整合
5. 身体感觉处理
6. 解离症状管理

**阶段3：整合与重建（第13-16周）**
1. 生命故事重写
2. 未来导向暗示
3. 关系修复暗示
4. 复发预防策略
5. 长期管理计划
6. 随访计划制定

**安全措施：**
1. 确保来访者有足够的稳定化技能
2. 在情绪窗口内工作
3. 准备危机干预计划
4. 与其他治疗师协调
5. 定期评估进展

## 儿童催眠治疗协议

### 儿童焦虑催眠治疗协议

**患者选择标准：**
1. 年龄6-12岁
2. 符合焦虑障碍诊断
3. 愿意参与催眠游戏
4. 父母同意并支持

**治疗方案：**

**第1-2周：建立关系**
- 游戏化评估
- 建立信任关系
- 父母教育
- 安全地带建立（游戏化）

**第3-4周：技能培养**
- 呼吸游戏
- 想象游戏
- 放松游戏
- 自信游戏

**第5-6周：问题处理**
- 恐惧游戏暴露
- 焦虑管理游戏
- 问题解决游戏
- 社交技能游戏

**第7-8周：巩固与泛化**
- 成功经验强化
- 技能泛化训练
- 父母培训
- 长期维护计划

**父母参与：**
- 每次治疗前后简短会谈
- 家庭练习指导
- 进展反馈
- 危机处理指导

## 团体催眠治疗协议

### 压力管理团体催眠协议

**团体设置：**
- 人数：8-12人
- 频率：每周1次
- 时长：90分钟

- 催眠介绍
- 初次体验

**第2次：放松技能训练**
- 渐进放松
- 呼吸催眠
- 安全地带建立
- 自我催眠入门

**第3次：认知重构**
- 压力思维识别
- 认知重构暗示
- 积极自我对话
- 问题解决暗示

**第4次：情绪管理**
- 情绪觉察
- 情绪调节暗示
- 情绪释放技术
- 情绪平衡暗示

**第5次：身体管理**
- 身体觉察
- 肌肉放松深化
- 睡眠改善暗示
- 能量恢复暗示

**第6次：人际关系**
- 沟通技能暗示
- 边界设定暗示
- 同理心增强
- 关系改善暗示

**第7次：职业发展**
- 工作效率暗示
- 创造力增强
- 领导力暗示
- 职业满足感

**第8次：整合与维持**
- 技能整合
- 长期维护计划
- 复发预防
- 团体结束

**评估指标：**
- 压力感知量表
- 焦虑量表
- 抑郁量表
- 睡眠质量
- 生活满意度
- 团体满意度

## 自我催眠训练协议

### 4周自我催眠训练方案

**第1周：基础训练**
- 每日练习：10分钟
- 内容：
  1. 呼吸催眠（3分钟）
  2. 身体扫描（4分钟）
  3. 安全地带想象（3分钟）

**第2周：深化训练**
- 每日练习：15分钟
- 内容：
  1. 呼吸催眠（3分钟）
  2. 渐进放松（5分钟）
  3. 倒数深化（4分钟）
  4. 安全地带想象（3分钟）

**第3周：暗示训练**
- 每日练习：15分钟
- 内容：
  1. 呼吸催眠（3分钟）
  2. 渐进放松（4分钟）
  3. 倒数深化（3分钟）
  4. 自我暗示（5分钟）

**第4周：应用训练**
- 每日练习：15-20分钟
- 内容：
  1. 呼吸催眠（3分钟）
  2. 渐进放松（4分钟）
  3. 倒数深化（3分钟）
  4. 问题导向暗示（5-10分钟）

**评估：**
- 每日练习记录
- 每周自我评估
- 第4周综合评估
- 后续维护计划
