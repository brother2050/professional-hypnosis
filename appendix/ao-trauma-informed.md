# 附录 AN：催眠与创伤知情照护

> **定位**：本附录面向已掌握基础催眠技术的从业者，提供将催眠工作置于"创伤知情"（Trauma-Informed）框架内的系统指南。创伤知情不是一种新技术，而是一种**贯穿所有催眠实践的视角、态度与安全架构**。它回答的核心问题是：*"这位来访者的症状在多大程度上是过去创伤的适应性反应？我的催眠工作如何避免再创伤化，并成为修复性体验的一部分？"*

---

## 一、创伤知情照护原则：SAMHSA 六原则与催眠的整合

美国药物滥用与精神卫生服务管理局（SAMHSA）提出的六项创伤知情原则，构成了本附录的伦理与实践骨架。下表将其翻译为催眠室中的具体行为：

### 1. 安全（Safety）

- **含义**：来访者在身体与情感上都感到安全，包括对催眠本身的可控感。
- **催眠整合**：
  - 入门前说明催眠全过程：会做什么、不会做什么、随时可睁眼、可叫停；
  - 明确"**你始终是主导者，我只是向导**"；
  - 房间布置可预测：门不锁、灯光稳定、来访者背靠墙而坐；
  - 避免突然的触碰、音量变化或黑暗环境。

### 2. 信任与透明（Trustworthiness & Transparency）

- **含义**：决策与流程对来访者可见、可理解、可预期。
- **催眠整合**：
  - 每一步先预告再执行（"接下来我会请你想一个安全的地方，你可以自己选，选好了告诉我"）；
  - 不隐瞒诱导话术的目的；不使用来访者不理解的"黑箱"技术；
  - 明确保密范围及其法定例外（自伤/伤人/虐待儿童等）。

### 3. 同伴支持（Peer Support）

- **含义**：借助"过来人"的经验与陪伴促进恢复。
- **催眠整合**：
  - 在合适情境下推荐支持团体或同伴陪伴者；
  - 催眠中引入"见证者意象"（如想象一位理解你的人在旁陪伴）；
  - 避免把催眠师塑造成唯一救赎者（防止依赖与权力失衡）。

### 4. 协作与互惠（Collaboration & Mutuality）

- **含义**：权力被分享，决策共同制定。
- **催眠整合**：
  - 诱导词、意象、终止信号由来访者参与选择；
  - 定期"共同检查"："这个方向感觉对吗？需要调整吗？"
  - 将催眠脚本视为**草稿**而非处方。

### 5. 赋权、选择与发声（Empowerment, Voice & Choice）

- **含义**：创伤剥夺了控制感；疗愈必须归还控制感。
- **催眠整合**：
  - 提供**选择菜单**："你想先去安全地带，还是先建立资源？"
  - 强调来访者随时"踩刹车"的权利；
  - 避免命令式暗示（"你现在必须放松"）→ 改为邀请式（"如果你愿意，你可以注意到呼吸变得慢一些"）。

### 6. 文化、历史与性别敏感（Cultural, Historical & Gender Issues）

- **含义**：识别并回应文化背景、历史创伤与身份因素。
- **催眠整合**：
  - "安全地带"意象尊重来访者的文化语境（对某些来访者，"白色房间"安全，对另一些人可能陌生）；
  - 了解集体创伤（殖民、歧视、战争、移民）对个体的影响；
  - 反思自身偏见如何进入暗示语言（如对性别、身体、家庭结构的假设）。

> **临床提示**：当催眠工作出现任何"卡住"（阻抗、解离、情绪泛滥），先回问自己：*六原则中哪一条被破坏了？* 大多数卡点可追溯到安全感、控制感或透明度的缺失。

## 二、创伤对大脑和身体的影响

### 2.1 神经生物学：三重脑的失序

| 系统 | 结构 | 创伤下的变化 | 催眠中的对应 |
|------|------|--------------|--------------|
| 爬虫脑 | 脑干 | 长期处于生存警戒；惊跳反射增强 | 呼吸、节律、声音韵律调节 |
| 情绪脑 | 杏仁核、海马、下丘脑 | 杏仁核过度激活；海马萎缩→记忆碎片化、无时间感 | 意象、隐喻、记忆再巩固工作 |
| 理智脑 | 前额叶皮层 | 功能被抑制，"窗口期"变窄 | 认知整合、叙述重建 |

**关键机制**：创伤记忆以**感觉碎片**（图像、声音、气味、身体感觉）形式储存，缺乏时间戳与语言标签。这就是为什么来访者"知道已经过去了"却仍然在身体上重现——海马未能把记忆"归档"到过去。催眠的意象与隐喻恰恰可以在感觉层面与这些碎片对话。

### 2.2 应激反应：四种生存策略

面对威胁，自主神经系统自动调用生存策略，其层次为：

1. **战（Fight）**：愤怒、攻击、控制欲增强
2. **逃（Flight）**：焦虑、坐立不安、强迫性忙碌
3. **僵（Freeze）**：麻木、解离、"不在场"、瘫软
4. **讨好（Fawn）**：过度顺从、读空气、丧失边界

**催眠意义**：识别来访者的"默认生存策略"，避免在催眠中无意触发它。例如：
- 对"僵"型来访者，深度放松诱导可能触发放大解离 → 应使用**保持觉察的浅度诱导**（眼睛微睁、脚踩地面）；
- 对"讨好"型来访者，诱导词中的权威语气可能触发顺从假象（表面"进入催眠"，实际在表演） → 应强调选择权与"可以不配合"。

### 2.3 依恋与关系创伤

- 早期照料者的**不可预测、拒绝或侵入**，塑造了"关系=危险"的内隐模板；
- 催眠关系本身就是一个依恋场域：催眠师的语气、节奏、边界的一致性，都在传递"这段关系是安全、可预测的"；
- **修复性体验**往往不在暗示内容里，而在**关系过程**中：准时开始与结束、说到做到、接受来访者的"不"、在失误后坦诚修复。

### 2.4 身体的印记

创伤"活在身体里"（van der Kolk）：慢性肌肉紧张、呼吸浅快、内感受（interoception）紊乱——要么麻木，要么过度警觉。创伤知情催眠必须**从身体进入**，而非绕过身体：

- 从中性或舒适的身体部位开始（"先注意到手心的温度"），而非直接要求"放松全身"；
- 对躯体麻木者，不强迫感受，改用外部资源（视觉、听觉意象）先行。

## 三、创伤知情催眠的实践指南

### 3.1 建立安全感（Safety First）

**结构化安全协议（每次催眠前必做）：**

1. **定向（Orienting）**：确认来访者知道此刻的日期、地点、与你的关系；
2. **知情说明**：本次催眠的流程、预计时长、可预期的感受；
3. **同意与信号**：建立明确的停止信号（举手、睁眼、说"停"）；
4. **资源检查**："今天你的状态从 0 到 10 打几分？低于 4 分我们今天不做深度工作。"
5. **退出计划**：结束前有 5-10 分钟"回归"时间，结束后确认稳定才离开。

> **红线**：不在状态极差（强烈解离、急性危机、物质影响下）进行创伤加工类工作。此时只做稳定化。

### 3.2 避免再创伤化（Do No Harm）

再创伤化的常见路径与规避：

| 危险路径 | 表现 | 规避策略 |
|----------|------|----------|
| 过早暴露 | 来访者被拉入创伤记忆无法退出 | 严格稳定化先行；使用"保持距离"技术（看屏幕、隔着河、装进盒子） |
| 暗示性诱导 | 催眠师的提问"创造"了记忆 | 禁止引导性提问（"是不是你父亲打你？"）；只问开放式问题 |
| 解离加剧 | 来访者"消失"、眼神空洞 | 缩短诱导、增加定向锚点（脚踩地、手握扶手）、随时监测 |
| 情感泛滥 | 崩溃、闪回、无法收尾 | 预设"容器技术"；随时可刹车；分次处理，每次聚焦一小块 |
| 权威滥用 | 来访者"顺从"超出真实意愿 | 反复邀请选择；明说"你可以不配合"；避免绝对化暗示 |

### 3.3 资源导向方法（Resource-Oriented Approach）

**核心理念**：不是"挖出创伤"，而是"先建立足以承接创伤的内在与外在资源"。只有当**资源容量 > 创伤负荷**时，加工才安全。

- **内在资源**：安全之地、智者形象、保护者意象、过去的成功经验、身体舒适感；
- **外在资源**：信任的人、宠物、物品、团体、信仰、音乐、自然环境；
- **现实资源**：稳定的睡眠、饮食、工作、住所——任何稳定化都以现实生活稳定为前提。

> **经验法则**：如果来访者的资源清单写不满 5 条，先花几周建设资源，再考虑创伤加工。

### 3.4 权力和控制感（Empowerment & Control）

- **选择菜单技术**："我们今天有三条路：A. 继续深化安全之地；B. 探索那个'保护者'意象；C. 只做放松。你选哪个？或者提出 D。"
- **刹车与油门**：教会来访者用意象控制强度（"想象一个调节音量的旋钮，你自己转"）。
- **归还语言**：把暗示中的"我会让你…"全部改为"如果你愿意，你可以允许自己…"。

### 3.5 信任和透明（Trust & Transparency）

- **预告-执行-回顾**三步走：每一步先说将发生什么，再做，再问感受；
- **不藏私**：被问到"你刚才在做什么"时，坦率解释技术原理；
- **一致性**：准时、守约、对边界说到做到——对创伤来访者而言，**稳定可预测本身就是治疗**。

### 3.6 同伴支持（Peer Support）

- 在催眠之外构建支持网络：支持团体、康复同伴、家庭支持（经评估安全时）；
- 催眠内的"陪伴意象"：邀请来访者想象一位安全的陪伴者在侧；
- 催眠师自我警惕**唯一救世主情结**：目标是来访者的自主，不是对你的依赖。

## 四、创伤知情催眠技术

> **使用前提**：所有以下技术均须在充分稳定化之后使用；创伤加工技术建议由受过专门训练的从业者执行，并配备督导。

### 4.1 稳定化技术（Stabilization）

#### （1）安全地带（Safe Place / Safe/Calm Place）

**标准流程**：
1. 邀请来访者回忆或想象一个**完全安全、舒适**的地方（真实或虚构皆可）；
2. 逐步展开五感细节：看到什么、听到什么、身体感觉到什么温度与触感；
3. **赋予入口**：建立一个随时可进入的"开关"（如手放在胸前、一句短语、一张卡片上的符号）；
4. **测试与加固**：轻微引入一个中性干扰，练习快速回到安全地带；
5. **明确限制**：安全地带用于稳定，不用于逃避现实生活；若来访者的"安全之地"实际含有危险元素（如童年房间同时是虐待场所），须更换意象。

**案例 1**：来访者小 A（32 岁，童年情感忽视）在第二次会谈中出现明显解离——眼神涣散、语速变慢。催眠师停止原计划，改用安全地带技术："如果愿意，你可以想象一个只有你自己选择的地方，不需要告诉我那是什么。"小 A 选择了一个海边的清晨。催眠师只邀请她关注海浪的声音和脚下的沙子温度，**不追问任何创伤内容**。5 分钟后定向恢复，会谈以资源建设收尾。这次经历本身成为一次修复性体验：她的解离被温和接住，而不是被当作"问题"去挖掘。

#### （2）资源建设与植入（Resource Installation）

- **回忆锚定**：邀请来访者回忆一个"感到被爱/被尊重/有力量"的具体时刻，放大其视觉、声音、身体感觉；
- **多资源合并**：将 3-4 个资源意象整合为一个"资源库"（如一座花园，每株植物代表一个资源）；
- **人物资源**：真实人物、虚构人物、动物、甚至未来自我，皆可成为资源意象；
- **身体锚点**：资源感受最强时，让手做一个特定手势（如拇指与食指相触），形成可复用的"开关"。

#### （3）容器技术（Container Technique）

- **适用**：侵入性画面、无法立即处理的情绪、会谈间的"遗留材料"；
- **流程**：想象一个坚固的容器（保险箱、宝箱、带锁的抽屉），由来访者决定材质、锁的类型、存放位置；把未处理的感受/画面**主动、完整**地放进去，锁好，并明确"它不会消失，只是暂时存放，我们可以决定何时取出"；
- **关键**：容器必须**由来访者设计并掌控**——催师不指定"一个铁箱"。

#### （4）观察性自我 / 距离化技术

- **屏幕技术**：把记忆放在房间另一端的屏幕上，来访者手持遥控器，可调音量、可暂停、可快进；
- **时间线视角**：站在时间线上方俯瞰事件，感受"那是过去的我经历的，现在的我在这里"；
- **火车意象**：记忆是窗外驶过的车厢，可以看，也可以不看，火车会驶过。

### 4.2 创伤加工（Trauma Processing）

> **警告**：以下技术触及创伤材料，只在稳定化充分、治疗联盟牢固、来访者状态良好（自评 ≥ 6/10）时使用。

#### （1）资源植入与资源桥

- 在进入创伤材料**之前**，先在身体或意象中安放资源锚点（如"安全之地的那股温暖现在留在你的左手"）；
- 当创伤材料被激活、情绪强度上升时，立即调用资源锚点**对冲**，形成"资源-材料"的往返摆动（类似 EMDR 的容器-资源交替）；
- 强度超过 7/10 时立刻退出，回到安全地带。

#### （2）情感桥（Affect Bridge）

- 从**当下的症状**（如"每次被批评就心慌"）出发，邀请来访者让身体的感觉带着他/她回到相关的记忆："如果这个心慌有记忆，它会带你去哪里？"
- **创伤知情修正**：
  - 只允许**来访者的潜意识选择记忆**，催眠师不指定；
  - 随时监测解离指标，出现即中断；
  - 记忆以"观察"方式进入（看屏幕），而非"重历"（第一人称），除非来访者明确要求且资源充分。

#### （3）记忆再巩固（Memory Reconsolidation）

记忆再巩固是创伤加工的现代神经科学核心：当一段记忆被**激活并进入可塑状态**（reconsolidation window，约 5 小时内），注入**与原预期矛盾的新体验**，记忆可以被改写而非仅被"覆盖"。

**催眠实施要点**：
1. **激活（Unlock）**：温和唤起记忆的关键元素（感觉、信念），仅到中等强度（4-6/10）；
2. **注入矛盾体验（Mismatch）**：
   - 成年自我的资源带入（"现在的你回到那个场景，你会对 8 岁的自己说什么、做什么？"）；
   - 保护者意象介入（"如果有一位完全站在你这边的保护者在场，会发生什么不同？"）；
   - 身体层面的改写（在记忆场景中体验"能呼吸、能动、能逃"——针对"僵"反应的修复）；
3. **重新储存（Reconsolidate）**：让新体验完整地"落座"，用身体感受新的结论，配对锚点；
4. **巩固（Consolidate）**：会谈后布置简短的日常锚定练习，24 小时内避免新刺激。

**案例 2**：来访者小 B（41 岁，车祸后应激）每次坐副驾驶位即恐慌。在四次稳定化会谈后，治疗师用情感桥带回车祸瞬间（以屏幕视角观察）。激活至 5/10 时，引入矛盾体验：让"现在的自己"坐进那个画面，握住方向盘侧的车门把手，**体验"这一次我有出口、可以动"**。恐惧峰值从 5 降到 2，身体的僵硬感转为温热。此后配对锚点（右手握拳），并在后续两周的日常通勤中反复调用。六周后随访：副驾驶焦虑评分从 9 降至 2。

### 4.3 整合与重建（Integration & Reconstruction）

- **叙事整合**：把碎片化记忆放入有时间顺序的叙事（"那件事发生在……之后是……现在我在……"），恢复海马的时间标记功能；
- **意义重建**：不强求"正能量"，允许复杂意义共存（"那是可怕的，同时它让我知道边界的重要"）；
- **身份重建**：创伤常伴随"我是破碎的"信念 → 催眠中建构"整合自我"意象（如破碎的陶器被金缮修复——裂痕成为历史的一部分，而非耻辱）；
- **身体重建**：恢复内感受（"现在注意心跳，它是属于此刻的"）；温和的身体活动（瑜伽、舞蹈、呼吸练习）配合催眠锚点；
- **关系重建**：在催眠中排演新的关系剧本（设定边界、表达需求），迁移到现实生活。

## 五、复杂性创伤的催眠处理

复杂性创伤（C-PTSD / 发展性创伤）源于**长期、重复、关系内**的创伤（虐待、忽视、长期家暴），其特征超出 PTSD 范围：情绪调节困难、自我组织受损、关系模式紊乱、常伴解离结构（部分化/人格状态）。

### 5.1 与单次创伤的关键差异

| 维度 | 单次创伤（PTSD） | 复杂性创伤（C-PTSD） |
|------|------------------|----------------------|
| 创伤来源 | 一次性事件 | 长期、重复、关系内 |
| 记忆特征 | 相对清晰的闯入记忆 | 碎片化、身体化、身份化 |
| 治疗阶段 | 稳定化+加工可较快衔接 | 稳定化可能需数月，加工需反复分层 |
| 关系议题 | 相对次要 | 核心（创伤发生在关系里，也须在关系里修复） |
| 自我结构 | 相对完整 | 常有部分化/内在冲突 |

### 5.2 分阶段模型（Herman 三阶段）在催眠中的应用

1. **第一阶段：安全与稳定化**（可能占总时长 50% 以上）
   - 情绪调节技能、安全地带、容器、内在安全岛群；
   - 内在部分的初步认识（"有一部分总在讨好，有一部分总在愤怒——它们都是保护策略"）；
   - **不急于进入创伤记忆**。
2. **第二阶段：创伤记忆加工**
   - 分层、分片段处理；每次只碰一小块，配对资源；
   - 对解离性部分使用**内在协作**框架（与部分对话、协商、尊重其保护功能）；
   - 处理哀伤（为失去的童年、未曾得到的照料）。
3. **第三阶段：整合与再连接**
   - 身份整合、关系模式更新、生活重建；
   - 告别仪式、未来自我意象。

### 5.3 解离性来访者的催眠适配

- **浅度优于深度**：深度催眠可能复制创伤中的"失控-服从"结构；使用浅至中度、保持观察自我的诱导；
- **定向锚点常备**：脚踩地面、手持物件、眼睛微睁可选；
- **监测解离信号**：眼神空洞、语速骤变、"我不知道我在哪"、身体僵硬 → 立即定向（"感觉你的脚，看看房间里的三样东西"）；
- **禁忌**：不使用年龄回溯、不使用"抹去记忆"类暗示、不使用未经训练的"人格部分"深度整合技术。

### 5.4 案例片段：内在部分的协作

来访者小 C（29 岁，长期童年情感虐待）在催眠中遇到"一个总在批评我的声音"。催眠师没有试图消除它，而是邀请对话："如果那个声音是一位保护者，它想保护你不受到什么？"小 C 落泪："它想让我先批评自己，这样别人批评我时不会那么痛。"催眠师邀请小 C 对这份保护表达感谢，并协商新的分工："你可以继续提醒我注意，但把批评的音量从 10 降到 3，好吗？"数次会谈后，自我批评的强度明显下降——**不与部分为敌，而是把敌人转化为盟友**，这是复杂性创伤催眠工作的核心姿态。

## 六、催眠师的创伤知情自我评估

### 6.1 会谈前自查（每节 2 分钟）

- [ ] 我今天的状态是否稳定？（自我状态 ≥ 6/10 才适合做创伤工作）
- [ ] 我是否了解这位来访者的触发点与默认生存策略？
- [ ] 我是否准备好了停止信号、定向话术、应急计划？
- [ ] 我今天的计划是否留有余地，允许"不按计划走"？

### 6.2 会谈中监测清单

- [ ] 来访者是否仍在"窗口期"内（有感受但未被淹没）？
- [ ] 我是否在使用选择式而非命令式语言？
- [ ] 我是否在询问开放性问题，而非植入性问题？
- [ ] 我是否注意到解离/泛滥的早期信号？
- [ ] 我是否把控制感留在来访者手里（旋钮、遥控器、刹车）？

### 6.3 会谈后反思（5 分钟日志）

1. 今天最强的时刻是什么？最紧张的时刻是什么？
2. 我有无越界冲动（想替来访者做决定、想"救"他/她、想延长会谈）？
3. 我有无被触发？（来访者的故事是否唤起我的创伤/未竟议题？）
4. 下次会谈的稳定化优先级是什么？

### 6.4 创伤知情胜任力自评量表（1-5 分）

| 项目 | 1 | 2 | 3 | 4 | 5 |
|------|---|---|---|---|---|
| 我能清晰说出 SAMHSA 六原则并在催眠中应用 | | | | | |
| 我能识别四种生存策略及其催眠含义 | | | | | |
| 我熟练掌握至少 3 种稳定化技术 | | | | | |
| 我能在发现解离信号时 30 秒内执行定向 | | | | | |
| 我能区分"资源充分"与"资源不足"的判断标准 | | | | | |
| 我理解记忆再巩固的三步骤并能实施 | | | | | |
| 我知道何时转介给创伤专科治疗师 | | | | | |
| 我有稳定的督导/同伴支持渠道 | | | | | |
| 我能识别自身被触发的信号并有应对方案 | | | | | |
| 我的知情同意文件明确涵盖创伤工作的风险 | | | | | |

**解读**：≤ 25 分：先补稳定化与伦理基础，暂不开展创伤加工；26-40 分：可在督导下开展工作；> 40 分：可独立开展，仍建议持续督导。**分数是镜子，不是奖杯——重新评估应每 6 个月一次。**

## 七、伦理考量和安全边界

### 7.1 知情同意的创伤知情扩展

除常规知情同意外，创伤工作须额外说明：
- 催眠可能激活强烈情绪或身体感觉，属可预期过程，但可随时暂停；
- 记忆的可塑性：催眠中出现的"记忆"可能包含建构成分，**不作为法律事实认定依据**；
- 不承诺"治愈"或具体次数；
- 保密及其法定例外；
- 转介与协作方案（与精神科医生/治疗师的信息共享，经书面授权）。

### 7.2 能力边界：何时停止、何时转介

**立即停止并评估转介的信号**：
- 急性自杀/自伤风险、精神病性症状（幻觉、妄想）；
- 严重解离障碍（身份切换、长期失忆）超出自身训练范围；
- 未成年人或无行为能力者的创伤披露（触发法定报告义务）；
- 来访者出现持续的功能恶化；
- 来访者与催眠师之间出现强烈移情/反移情纠缠。

**转介不等于失败**：清晰说明"这部分工作需要比我更专业的支持，我会陪你找到合适的资源"——这本身即是赋权与透明的示范。

### 7.3 双重关系与权力滥用防范

- 严禁与来访者发展亲密/性关系（包括治疗结束后相当长时期内）；
- 警惕催眠中的权力快感："我能影响他"的满足感是危险信号；
- 不在催眠中植入任何服务于催眠师自身利益的暗示；
- 馈赠、额外联系、延长会谈均需在督导中审视。

### 7.4 催眠师的自我保护与耗竭预防

- **替代性创伤（Vicarious Trauma）**：长期接触创伤材料会改变从业者的安全感、信任与世界观。信号：噩梦、易怒、过度警觉、情感麻木、对来访者产生拯救或厌弃的极端情绪。
- **预防措施**：
  - 每周固定督导/同伴讨论；
  - 限制每日创伤工作会谈数量（建议 ≤ 3 节）；
  - 建立自己的稳定化练习（催眠师也需要安全地带）；
  - 会谈间的"清理仪式"（洗手、深呼吸、切换环境——象征性结束）；
  - 定期休假与个人体验（自己的治疗）。
- **底线**：耗竭状态下的催眠师无法提供安全。**先戴好自己的氧气面罩。**

### 7.5 技术伦理的三条红线

1. **不做记忆考古**：不追问、不诱导、不"挖掘被压抑的记忆"；让记忆按自己的节奏浮现；
2. **不做暗示植入**：不植入服务于治疗师意志的信念、价值观或行为；
3. **不做单次奇迹承诺**：创伤修复以月、年计；任何"一次催眠清除创伤"的宣传本身即是伦理问题。

---

## 结语：创伤知情催眠的本质

创伤知情催眠不是把"创伤"标签贴在每位来访者身上，而是带着这样一种假设进入每一次会谈：

> **"你的症状曾经是你的生存方式。我们不急于拆除它，我们先感谢它、理解它，然后在足够安全的关系中，一起发现还有哪些新的可能。"**

技术会迭代，神经科学会更新，但这三件事不会过时：**安全、选择、关系**。当这三者在催眠室中被真实地体验，疗愈已经在发生——无论是否使用深度诱导。

## 附：一页纸速查表

**会谈前**：状态自查（≥6/10）→ 了解触发点与生存策略 → 准备停止信号与应急计划
**会谈中**：预告-执行-回顾 → 选择式语言 → 监测解离（眼神/语速/僵硬）→ 控制旋钮交给来访者
**技术顺序**：定向 → 安全地带 → 资源建设 → （资源 > 负荷时）分层加工 → 资源锚定 → 整合叙事 → 回归定向
**危机处理**：发现泛滥/解离 → 停止加工 → 定向（脚踩地/三样东西）→ 安全地带 → 评估状态 → 决定继续或收尾
**会谈后**：5 分钟反思日志 → 越界冲动检查 → 自我触发检查 → 督导需要时上报
**长期**：每 6 个月重评胜任力量表 → 固定督导 → 限制每日创伤会谈 ≤ 3 节 → 维护自己的安全地带
