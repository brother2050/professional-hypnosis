# 附录 AT：催眠与心身医学的整合

> **临床定位**：本附录面向从事心身医学、健康心理学、心理治疗与整合医学的临床工作者，系统阐述催眠干预在心身疾病（psychosomatic disorders / somatoform and stress-related disorders）中的循证应用、生理机制与多学科整合管理方案。所有方案均需在明确的医学评估与诊断基础上实施，催眠不替代必要的器质性疾病诊疗。

---

## AT.1 心身医学的现代理解

### AT.1.1 从"心身二元"到"心身互动网络"

心身医学（psychosomatic medicine）的现代范式已超越经典的精神分析性"心身二元论"，转向**生物-心理-社会-行为整合模型**。其核心命题是：

1. **心理过程具有生理载体**：情绪、认知、预期、注意与意义感均以神经环路、神经内分泌与免疫活动的形式实现。
2. **生理状态反向塑造心理**：内感受（interoception）、自主神经张力、炎症信号通过脑-体与体-脑通路影响情绪、动机与认知（如炎症相关的"疾病行为"、疲乏、快感缺失）。
3. **心身症状是真实的功能性改变**，而非"想象"或"伪装"。功能性症状伴随可测量的脑功能与自主神经改变，患者承受的痛苦是真实的。

现代诊断系统（DSM-5 的躯体症状及相关障碍、ICD-11 的躯体不适或躯体体验障碍、功能性神经障碍）已将重点从"病因是否为心理"转向**症状的功能性影响、疾病行为与医患沟通质量**，减少对"医学无法解释"（MUS）标签的依赖，强调"功能性"与"困扰/功能损害"的双轴描述。

### AT.1.2 压力生理学：从急性适应到慢性损耗

压力反应由三条主要通路构成：

| 通路 | 关键介质 | 主要效应 | 慢性激活后果 |
|---|---|---|---|
| 下丘脑-垂体-肾上腺轴（HPA） | CRH → ACTH → 皮质醇 | 代谢动员、抗炎、警觉 | 皮质醇节律扁平化、糖皮质激素抵抗 |
| 交感-肾上腺髓质系统（SAM） | 儿茶酚胺（E/NE） | 心率↑、血压↑、血流重分布 | 高血压、内脏缺血、免疫偏移 |
| 自主神经-迷走通路 | 乙酰胆碱、心率变异性（HRV） | 炎症反射、社会参与 | 迷走张力下降、炎症失控 |

**Allostasis 与 Allostatic Load**：压力系统以"变异性维持稳定"（allostasis）方式适应环境，但长期或反复的超负荷导致"异稳态负荷"（allostatic load）累积，表现为：皮质醇昼夜节律紊乱、交感优势、内脏脂肪堆积、胰岛素抵抗、内皮功能障碍、慢性低度炎症（meta-inflammation），最终形成心身疾病的躯体土壤。

**关键临床推论**：
- 心身症状常出现在压力系统"失代偿"阶段，而非压力最高点——患者常主诉"事情已经过去了，身体却垮了"。
- 症状的波动与生活事件、预期性焦虑、疾病行为（反复就医、检查寻求、活动回避）形成**恶性循环**。
- 治疗目标不是"消除压力"，而是**恢复调节能力与灵活性**（regulatory flexibility），这正是催眠干预的核心靶点。

### AT.1.3 神经免疫学：心理如何"进入"身体

神经免疫学揭示了心理过程影响躯体的具体通路：

1. **交感神经支配免疫器官**：脾、淋巴结、骨髓受交感神经直接支配，去甲肾上腺素调节淋巴细胞增殖、细胞因子产生与免疫细胞归巢。
2. **迷走神经抗炎通路（炎症反射）**：迷走传入感知外周炎症 → 脑干孤束核 → 迷走传出 → 脾交感神经 → 释放乙酰胆碱 → 巨噬细胞 α7nAChR → 抑制 TNF-α、IL-1β、IL-6。**这是催眠可直接调控的通路**。
3. **糖皮质激素抵抗**：慢性压力使免疫细胞对皮质醇的抗炎信号敏感性下降，炎症因子持续升高，进一步作用于脑（杏仁核、前扣带、岛叶），加剧焦虑、疼痛与疲乏。
4. **细胞因子的中枢效应**：IL-1β、IL-6、TNF-α、IFN-α 通过迷走传入、血脑屏障转运与小胶质细胞激活，引起"疾病行为"：疲乏、睡眠紊乱、快感缺失、认知迟缓、疼痛敏化——与慢性疲劳、纤维肌痛、抑郁高度重叠。
5. **表观遗传与早期经验**：早期逆境（ACE）通过表观遗传机制设定 HPA 轴与免疫系统的反应阈值，构成心身疾病的易感背景；但这种设定在成年期仍具可塑性，为心理干预提供了生物学合理性。

### AT.1.4 心身互动的临床表现谱

- **压力直接介导**：应激性溃疡、原发性高血压、紧张型头痛、心因性闭经。
- **功能性障碍**：肠易激综合征、功能性神经症状、纤维肌痛、慢性疲劳综合征。
- **疾病行为放大**：躯体形式障碍、健康焦虑、慢性疼痛灾难化。
- **心身共病**：心血管疾病、糖尿病、自身免疫病、肿瘤中的心理应激与依从性问题。

## AT.2 催眠在心身疾病中的应用：循证综述

### AT.2.1 肠易激综合征（IBS）——最强证据领域

**证据等级**：高。肠道导向催眠疗法（gut-directed hypnotherapy, GDH）是 IBS 循证治疗中证据最充分的心理干预，被 NICE、ACG、AGA 指南列为难治性 IBS 的推荐方案。

**代表方案**：
- **Manchester 方案（Whorwell）**：12 次、每次 30 分钟、每周一次的标准化治疗，联合音频家庭练习，随访研究显示 70–80% 患者症状显著改善，疗效维持 1–5 年，部分患者可减少药物使用。
- **North Carolina（Palsson）标准化方案**：7 次会诊 + 家庭音频，采用"温热手部""肠道平静意象""注意力转移"等固定脚本，适合常规临床与远程实施。
- **远程/自助模式**：研究显示基于录音或数字平台（如 Nerva、Regulora 类应用）的引导式催眠可获得中-大效应量改善，扩大了可及性。

**作用机制**：
- 纠正**内脏高敏感**（降低直肠气囊扩张的痛觉阈值）；
- 调节**脑-肠轴**（前扣带、岛叶、前额叶对内脏信号的处理）；
- 降低内脏运动亢进与转运异常；
- 减少灾难化认知与疾病行为，改善生活质量与就医频率。

**治疗要点**：
1. 明确诊断（罗马 IV 标准），排除报警征象（便血、体重下降、夜间症状、贫血、发病年龄>50 岁、家族史）。
2. 以**肠道意象**为核心：温热感、"平静的河流"、"为肠道做轻柔按摩"、手部热传导至腹部。
3. 强调**自主神经放松**与"让肠道自己工作"的暗示，避免控制性暗示（如"必须停止痉挛"）。
4. 家庭练习是疗效维持的关键，需结构化依从性管理。
5. 对检查寻求与反复就医，加入**症状重构**与就医行为计划。

### AT.2.2 纤维肌痛

**证据等级**：中等（小样本 RCT、前后对照与临床系列支持）。

**核心靶点**：中枢敏化、疼痛灾难化、睡眠障碍、压力调节失灵。

**方案要点**：
- **多模式催眠**：催眠镇痛（深度放松 + 感觉重编码）+ 睡眠暗示 + 活动节律管理。
- **意象策略**：将弥漫性疼痛重构为"过度敏感的警报系统"，用"调低音量""温热流动""浸入温水"等感觉性暗示进行脱敏。
- **行为整合**：分级活动（pacing）+ 睡眠卫生 + 压力管理，避免"痛-回避-失能-更多痛"循环。
- **疗效指标**：疼痛强度、压痛点敏感性、FIQ（纤维肌痛影响问卷）、睡眠质量、情绪。

**注意**：不承诺"治愈"，以功能改善与自我调节能力为主要目标；与药物（SNRI、普瑞巴林）与运动疗法联合优于单一干预。

### AT.2.3 慢性疲劳综合征（ME/CFS）

**证据等级**：有限但积极；个案系列与前后研究提示催眠可改善疲乏、睡眠与应对。

**治疗焦点**：
1. **节律重建**：睡眠-觉醒节律、活动-休息节律的暗示性指导。
2. **能量意象**："充电""能量从太阳流入""细胞修复"等意象，避免引发运动不耐受（PEM）的暗示。
3. **疼痛与睡眠共病**处理。
4. **疾病行为修正**：减少过度休息与过度活动的两极摆动，建立"节律生活"。
5. **意义与身份重构**：从"病人身份"转向"带症状的完整生活"。

**禁忌性提示**：不得暗示"症状是想象的"或要求患者突破身体极限；对存在体位性心动过速、免疫异常者，治疗须与医学随访同步。

### AT.2.4 功能性神经症状（Functional Neurological Disorder, FND）

**证据等级**：中等，多项临床系列与 RCT（如 Jordbru 等对功能性震颤/无力的催眠研究）显示显著改善。

**治疗原则**：
- **症状可塑性示范**：在催眠中观察症状波动（如震颤幅度、无力改善），强化"神经系统可重新学习"的解释模型。
- **注意-意图分离**：FND 的特征是"意图-运动"耦合异常与过度自我监控；催眠通过**外部注意焦点**、自动性暗示（"让手自然地做"）、分离意象（"让动作自己发生"）打断该循环。
- **意象再训练**：想象动作流畅完成（运动意象训练与催眠结合）。
- **创伤与情绪整合**：如存在创伤史，在稳定化后处理；不强迫创伤暴露。
- **解释框架**：使用"软件故障而非硬件损坏""信号传递问题"等中性、去污名化解释，可显著提升疗效预期与治疗联盟。

### AT.2.5 转换障碍（Conversion Disorder，现归入 FND）

**历史与现代地位**：催眠是历史上最早的转换症状治疗之一（Charcot、Bernheim 时代），现代应用强调：

1. **暗示感受性评估**：转换症状患者常具较高暗示感受性，症状可在催眠中被复现或改变，治疗性利用这一点。
2. **症状诱导-再消除**：在深度催眠中先轻度诱导类似体验（使患者体验"症状是我制造的"），再诱导消除与正常功能——重建自我效能。
3. **功能恢复训练**：催眠中反复排练正常动作/感觉，配合实际功能训练。
4. **二级获益识别**：以非羞辱方式处理症状维持因素。

### AT.2.6 躯体形式障碍 / 躯体不适或躯体体验障碍

**治疗核心**（结合 CBT-SO 与催眠）：
1. **症状重构**：将症状解释为"压力生理 + 中枢放大"，而非"心理虚构"，尊重患者痛苦。
2. **内感受再训练**：在催眠中练习对身体信号的**非灾难化注意**（"注意到，允许它，让它变化"）。
3. **减少疾病行为**：设定就医与检查计划、减少症状监测、恢复活动。
4. **情绪表达通道**：为无语言化的情绪提供表达（意象、隐喻、身体感受命名）。
5. **医患沟通**：定期、简短、结构化的医学随访比反复检查更有效——催眠治疗师应与初级保健/专科医师协同。

## AT.3 催眠与自主神经调节

### AT.3.1 生理基础

催眠状态伴随可重复的自主神经特征：
- **交感活性下降**：血压、心率、外周血管阻力适度下降；
- **迷走张力提升**：心率变异性（HRV，尤其高频成分）升高，反映副交感调节能力增强；
- **呼吸性窦性心律不齐增强**：提示呼吸-迷走耦合改善；
- **皮质醇节律恢复**：部分研究显示晨起皮质醇正常化、全天曲线下面积下降；
- **外周温度与血流调节**：手部温热意象可引起可测量的外周血管扩张。

### AT.3.2 临床技术组合

1. **呼吸-迷走耦合训练**：4-6 次/分的谐振呼吸（吸 4-5 秒、呼 5-6 秒）作为催眠导入与核心练习，直接提升 HRV。
2. **温热手部技术**（Schultz 自生训练改良）：暗示手部温热、沉重，作为副交感激活与"可控感"的锚点。
3. **内感受安全训练**：在催眠中以温和剂量接触心跳、呼吸、内脏感觉，练习"观察而不反应"，降低内脏高敏感与惊恐相关的躯体放大。
4. **生物反馈整合**：HRV 生物反馈 + 催眠是心身疾病（尤其 IBS、原发性高血压、雷诺现象、功能性心律失常）的高效组合，患者对自主神经变化的感知与控制能力同步增强。
5. **锚定技术**：将"平静-温热-呼吸平顺"状态锚定为一个可快速调用的日常状态（如拇指-食指触碰），用于症状发作情境。

### AT.3.3 自主神经评估建议

- 基线与随访测量 HRV（RMSSD、SDNN、LF/HF 解释需谨慎）、血压、症状日记；
- 简易指标：呼吸频率、静息心率、手掌温度、主观紧张度 0-10 分；
- 对晕厥、体位性低血压、心动过缓患者慎用强深度放松诱导，采用坐位、渐进式方案。

## AT.4 催眠与免疫功能

### AT.4.1 现有证据

心理神经免疫学（PNI）研究提示催眠/深度放松可对免疫指标产生可测量影响：
- **NK 细胞活性**：放松训练与催眠在部分研究中维持或提升 NK 细胞活性，尤其在压力人群；
- **淋巴细胞增殖反应**：放松与催眠后对丝裂原的反应改善；
- **疫苗反应**：催眠 + 放松组对流感疫苗的抗体滴度优于对照（Kiecolt-Glaser 等系列研究）；
- **伤口愈合**：放松/催眠干预显著加速术后与烧伤伤口愈合（Harvard/MGH 系列），提示免疫-修复功能增强；
- **IgA 分泌**：口腔分泌型 IgA 在催眠与正性情绪诱导后短暂升高。

### AT.4.2 临床应用框架

1. **肿瘤支持治疗**：催眠用于围手术期（疼痛、焦虑、止血、恢复）、化疗相关恶心呕吐、癌因性疲乏、临终舒适照护。**明确边界**：不主张以催眠"治疗肿瘤"，而是改善生活质量、依从性与应激相关免疫抑制。
2. **自身免疫与炎症性疾病**：作为应激管理手段，与免疫调节治疗并行，监测疾病活动指标，避免任何暗示"可停用免疫抑制剂"的表述。
3. **反复感染与免疫低下人群**：以睡眠、压力管理与行为健康为核心，间接支持免疫稳态。
4. **围手术期方案**：术前 1-2 次催眠（手术意象预演、止血与恢复暗示）、术中辅助、术后疼痛与恢复意象，可减少镇痛药用量与住院日。

### AT.4.3 机制假说（供临床解释使用）

- **HPA 轴正常化** → 糖皮质激素信号恢复 → 免疫细胞受体敏感性恢复；
- **迷走抗炎反射增强**（见 AT.5）；
- **睡眠质量改善** → 生长激素与免疫修复节律恢复；
- **行为路径**：依从性提高、健康行为增加、就医行为合理化。

## AT.5 催眠与炎症反应

### AT.5.1 炎症的心理调节证据

- **Careira 等（2013）**：单次放松训练即降低烧伤患者 IL-6 与促炎基因表达；
- **Bower 等**：乳腺癌幸存者身心干预降低 IL-6 与 NF-κB 通路活性；
- **催眠研究**：催眠镇痛与放松可降低急性应激后的炎症标记物反应；催眠深度与 HRV 提升相关，HRV 与炎症负相关；
- **期待与意义感**：治疗性情境、可控感与安全感本身即具有抗炎相关生理效应（通过迷走通路与皮质醇信号）。

### AT.5.2 "抗炎催眠"临床模块（可嵌入各疾病方案）

1. **炎症意象**："凉爽的清泉流过发热/红肿的组织""肿胀逐渐消退""免疫细胞有序工作"——以感觉具体化而非抽象暗示为佳。
2. **炎症反射激活**：呼吸 + 颈部/耳周区域注意（迷走神经分布区）+ 放松咽喉与面部，暗示"身体自带的消炎系统被唤醒"。
3. **生活方式协同**：催眠中强化抗炎行为暗示（规律睡眠、适度活动、抗炎饮食、减少酒精与烟），并以隐喻性排练巩固。
4. **指标监测**：条件允许时配合 hs-CRP、IL-6、ESR、HRV 等客观指标，提升患者信心与治疗可信度。

### AT.5.3 临床边界

- 炎症指标是辅助证据，不能替代疾病活动的医学评估；
- 对急性感染、自身免疫活动期，须以医学治疗为主，催眠仅作辅助；
- 避免暗示"炎症已消除"或"可以减少抗炎药/激素用量"，任何药物调整须由主治医师决定。

## AT.6 心身疾病的催眠治疗方案（完整模板）

### AT.6.1 通用方案结构（10 次核心疗程 + 强化）

| 阶段 | 次数 | 核心内容 |
|---|---|---|
| 1. 评估与联盟 | 第 1 次 | 医学记录回顾、症状与压力图、暗示感受性/催眠反应性评估、解释心身模型、共同设定目标 |
| 2. 自主神经稳定 | 第 2-3 次 | 催眠导入训练、呼吸-迷走训练、温热手部、睡眠锚定、家庭音频 |
| 3. 症状特异干预 | 第 4-7 次 | 疾病特异意象（肠道/疼痛/疲劳/功能症状）、内感受再训练、疾病行为计划 |
| 4. 认知-意义重构 | 第 8-9 次 | 症状重构、自我效能、身份与意义、复发预防 |
| 5. 巩固与泛化 | 第 10 次 | 自我催眠熟练化、情境排练（诱发情境）、随访计划 |
| 强化 | 1、3、6、12 月 | 单次强化、家庭练习复核、指标复测 |

### AT.6.2 通用治疗脚本骨架

```
【准备】舒适坐/半卧，医学评估已明确，安全与可控感暗示（"你始终保有控制，
随时可以睁开眼、说话、调整"）。
【导入】渐进放松或凝视-闭眼、呼吸计数、沉重/温热感（自生训练元素）。
【深化】楼梯/电梯下行、安全处所意象、年龄退行到"最轻松的时刻"（可选）。
【治疗核心】
  1) 疾病特异意象（见各病种）；
  2) 自主神经意象（呼吸平顺、心脏平稳、血流温暖/清凉）；
  3) 炎症/免疫意象（可选，见 AT.5.2）；
  4) 情绪释放与安全表达；
  5) 自我效能与功能排练。
【后催眠暗示】练习触发锚点、症状发作时的快速技术、愈后场景想象。
【唤醒】计数上行、定向、情绪检查、家庭练习分配与依从性确认。
```

### AT.6.3 病种特异模块

**IBS 模块**：手部温热 → 热量流入腹部 → "肠道像平静的河，缓慢规律地流动" → 肠壁放松、敏感度下降 → 便急/腹痛情境排练（"在任何场所都能保持平静与掌控"）。

**纤维肌痛模块**：全身浸入温水 → 疼痛信号"调低音量" → 肌肉如温暖的面团 → 睡眠深沉、晨起轻快 → 分级活动排练（"做得到，且不透支"）。

**CFS 模块**：能量充电意象（太阳/电池）→ 节律（活动-休息）可视化 → 睡眠修复意象 → "能量管理而非能量透支"的行为承诺。

**FND/转换模块**：症状轻度复现（可选、可控）→ 见证"这是神经信号模式，可被改变" → 正常功能意象排练（想象手稳稳握住、腿有力行走）→ 功能暗示（"动作自动、流畅、不需监控"）。

**躯体形式模块**：身体扫描以非灾难化注意 → "信号放大器"意象 → 允许不适存在并变化 → 就医与生活计划可视化。

### AT.6.4 自我催眠处方

- 每日 1-2 次、每次 15-20 分钟的家庭练习，配合结构化音频；
- 每周依从性记录（练习次数、症状评分 0-10、睡眠、功能）；
- 数字化工具（引导式音频/APP）可作为有效补充，尤其在可及性受限时。

### AT.6.5 疗效评估指标（建议组合）

- **症状**：病种特异量表（IBS-SSS、FIQ、FSS 疲劳量表、PHQ-15、SDQ-20 功能性症状量表）；
- **心理**：灾难化（PCS）、焦虑抑郁（GAD-7/PHQ-9）、自我效能（GSE）；
- **生理**：HRV、皮质醇节律（可选）、炎症标记物（可选）；
- **功能与行为**：就医次数、缺勤/社会功能、活动量、药物使用量。

## AT.7 心身疾病的多学科整合管理

### AT.7.1 整合照护的基本原则

1. **单一负责医师（gatekeeper）**：避免多科重复检查与矛盾解释，指定一位医师统筹医学评估与随访。
2. **一致性解释**：所有团队成员使用同一心身模型语言（"功能性/调节性问题"，而非"查不出病"）。
3. **以功能恢复为目标**：目标写成可观察的行为（恢复工作 3 天/周、独立出行），而非"症状完全消失"。
4. **计划性接触**：定期、简短、按计划随访替代按需急诊与重复检查。
5. **共决策**：患者参与目标设定与方案选择，增强可控感（可控感本身即治疗成分）。

### AT.7.2 团队角色分工

| 角色 | 主要职责 |
|---|---|
| 初级保健/心身医学科医师 | 诊断、医学监测、药物管理、计划性随访、解释框架 |
| 临床心理/催眠治疗师 | 催眠治疗、CBT/SO 组件、自我催眠训练、疗效评估 |
| 精神科医师 | 共病抑郁/焦虑/创伤、药物会诊、风险评估 |
| 理疗/康复治疗师 | 运动疗法、分级活动、姿势与呼吸训练 |
| 营养师 | 抗炎/肠道友好饮食、进食行为管理（IBS、代谢共病） |
| 社工/个案管理 | 生活压力源、工作与家庭系统、福利与就业支持 |
| 护理/健康教练 | 依从性支持、家庭练习辅导、数字工具指导 |

### AT.7.3 整合流程（建议）

1. **共同评估**（第 0 周）：医学 + 心理 + 功能评估，形成共享问题清单与目标；
2. **同步干预**（第 1-10 周）：催眠方案 + 医学管理 + 康复/营养，按需平行进行；
3. **团队沟通**：每 4 周简短病例会（15 分钟）或共享记录，确保解释一致；
4. **阶段复评**（第 6、12 周）：指标复测，调整方案；
5. **维持期**：1、3、6、12 月强化，复发早期识别与快速响应计划。

### AT.7.4 常见临床困境与处理

- **"查不出病"的挫败**：采用"功能性诊断 + 机制解释 + 治疗路径"三段式沟通，避免否定性表述。
- **检查寻求与多科就医**：设定结构化随访与检查"预算"，治疗师处理焦虑与不确定性耐受。
- **药物与催眠的协同**：催眠不替代必要药物；目标之一是使患者在医师指导下合理用药（减少非必要镇痛药/安眠药），任何减停由医师决定。
- **医患联盟断裂史**：催眠治疗中纳入既往就医创伤的处理，重建对医疗系统的信任。
- **家庭系统**：将家庭纳入心理教育，减少"疾病角色"强化与过度照顾。
- **远程与低资源情境**：标准化音频、数字 CBT/催眠平台、小组催眠课程可作为有效替代或补充。

### AT.7.5 质量与安全清单

- [ ] 医学评估已完成，报警征象已排除，诊断与随访计划明确；
- [ ] 患者理解并接受心身整合解释（书面心理教育材料）；
- [ ] 治疗目标为功能与自我调节，非"症状归零"；
- [ ] 催眠干预不暗示症状虚假、不替代药物、不承诺治愈；
- [ ] 团队解释语言一致，指定负责医师；
- [ ] 评估指标（症状、心理、生理、功能）在基线、6 周、12 周记录；
- [ ] 复发预防与快速响应计划书面化；
- [ ] 知情同意涵盖催眠性质、替代方案、可随时退出。

## 结语

心身疾病的现代管理已经从"证明症状是心理性的"转向**恢复调节灵活性与功能生活**。催眠干预以其对注意、内感受、自主神经、神经内分泌与免疫通路的独特调节能力，成为心身医学中少有的"跨通路工具"：它既能在脑-肠轴、中枢敏化、功能性神经环路层面直接作用，又能通过行为、意义与医患沟通层面间接放大疗效。将其置于多学科、以功能恢复为目标、以医学安全为边界的整体照护框架内，催眠从"辅助放松技术"升格为**心身医学的核心治疗组件**。
