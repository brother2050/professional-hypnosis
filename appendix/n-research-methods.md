# 附录N：催眠研究方法与循证实践指南

> **目标读者**：希望从事催眠研究或批判性评估催眠文献的研究者和临床工作者。

---

## 一、催眠研究设计

### 1.1 随机对照试验（RCT）

**设计要点：**

```
随机分配
    │
    ├── 催眠治疗组（实验组）
    │
    ├── 对照组选择：
    │   ├── 等待组（自然恢复）
    │   ├── 安慰剂对照（假催眠/注意力控制）
    │   ├── 常规治疗对照
    │   └── 主动治疗对照（如CBT）
    │
    └── 评估时间点：治疗前、中、后、随访
```

**盲法挑战：**
- 催眠研究无法实现双盲（治疗师和来访者都知道）
- 应对：使用盲法评估者、客观测量指标
- 安慰剂对照设计：注意力控制、假催眠

**样本量估算：**
- 催眠研究通常效应量为中等到大（Cohen's d = 0.5-1.0）
- 双侧检验α=0.05，1-β=0.80
- 通常需要每组20-40名被试

### 1.2 系统综述与Meta分析

**PICOS框架：**
- **P**（人群）：如"慢性疼痛患者"
- **I**（干预）：如"催眠治疗"
- **C**（对照）：如"常规治疗"
- **O**（结局）：如"疼痛强度"
- **S**（研究设计）：如"RCT"

**质量评估工具：**
- Cochrane偏倚风险评估
- GRADE证据质量评级
- Jadad量表

### 1.3 单被试实验设计

**适用场景：**
- 临床实践研究
- 罕见病例
- 个体化治疗评估

**常用设计：**
- ABAB设计（撤回设计）
- 多基线设计
- 交替处理设计

## 二、催眠研究的核心方法学挑战

### 2.1 盲法困难

**问题：** 催眠研究无法实现真正的双盲

**应对策略：**
1. 盲法评估者（不参与治疗）
2. 客观生理指标（fMRI、EEG、HRV）
3. 模拟催眠设计（假装催眠作为对照）
4. 注意力控制组（相同时间的治疗者关注）

### 2.2 安慰剂效应分离

**问题：** 催眠效果可能部分是安慰剂效应

**分离方法：**
1. 积极安慰剂对照（有效但非催眠特异性）
2. 比较催眠暗示vs非催眠暗示
3. 神经影像识别特异性机制
4. 剂量-反应关系分析

### 2.3 个体差异处理

**问题：** 催眠感受性的巨大差异影响结果

**处理方法：**
1. 按感受性分层分析
2. 将感受性作为调节变量
3. 使用混合效应模型
4. 大样本量

### 2.4 标准化vs个性化

**问题：** 标准化控制变量但降低生态效度

**平衡策略：**
1. 手册化但允许灵活调整
2. 模块化治疗设计
3. 适应性治疗方案
4. 混合方法研究

## 三、催眠研究的测量工具

### 3.1 主观测量

| 工具 | 测量内容 | 适用场景 |
|------|----------|----------|
| SHSS:A/B/C | 催眠感受性 | 入组筛选 |
| HGSHS:A | 团体感受性评估 | 研究筛选 |
| HIP | 催眠体验质量 | 深度评估 |
| VAS/NRS | 疼痛/焦虑强度 | 效果评估 |
| GAD-7/PHQ-9 | 焦虑/抑郁 | 共病评估 |

### 3.2 行为测量

- 标准化催眠行为测试
- 任务完成率
- 功能性评估

### 3.3 生理测量

| 指标 | 优势 | 局限 |
|------|------|------|
| 心率变异性（HRV） | 无创、实时 | 易受干扰 |
| 皮肤电导（SC） | 灵敏 | 易受环境影响 |
| 肌电图（EMG） | 客观 | 设备要求 |
| EEG | 高时间分辨率 | 空间分辨率低 |
| fMRI | 高空间分辨率 | 昂贵、不自然 |

## 四、循证实践的证据等级

### 4.1 证据等级体系

| 等级 | 证据类型 | 说明 |
|------|----------|------|
| Ia | 多项RCT的系统综述/Meta分析 | 最高证据 |
| Ib | 至少一项设计良好的RCT | 强证据 |
| IIa | 设计良好的非随机对照研究 | 中等证据 |
| IIb | 设计良好的准实验研究 | 中等证据 |
| III | 非实验性描述性研究 | 弱证据 |
| IV | 专家委员会报告/专家意见 | 最低证据 |

## 五、如何批判性评估催眠研究

### 5.1 评估清单

**方法学质量：**
- [ ] 是否有明确的研究问题？
- [ ] 样本量是否足够？
- [ ] 随机化是否恰当？
- [ ] 盲法如何处理？
- [ ] 是否有适当的对照组？
- [ ] 结局指标是否有效？

**统计分析：**
- [ ] 统计方法是否恰当？
- [ ] 是否报告效应量？
- [ ] 是否处理了缺失数据？
- [ ] 是否进行了亚组分析？

**报告质量：**
- [ ] 是否遵循CONSORT声明？
- [ ] 是否报告不良事件？
- [ ] 是否报告依从性？
- [ ] 是否有利益冲突声明？

### 5.2 识别研究偏倚

**常见偏倚：**
1. **选择偏倚**：样本不具代表性
2. **绩效偏倚**：治疗实施不一致
3. **检测偏倚**：结局评估不客观
4. **失访偏倚**：脱落不随机
5. **报告偏倚**：只报告阳性结果

## 六、实施研究与推广

### 6.1 从研究到临床

**转化路径：**
基础研究 → 临床前研究 → 临床试验 → 实施研究 → 临床推广

**实施研究的核心问题：**
- 治疗在真实世界中的效果如何？
- 哪些因素影响实施效果？
- 如何培训临床工作者？
- 如何确保治疗质量？

### 6.2 质量保证

**临床实践质量保证：**
- 标准化治疗方案
- 定期督导
- 治疗记录审查
- 效果持续监测
